# Dungeon entry fonts

`DungeonEntryKorean-Regular.asset` and `DungeonEntryKorean-Bold.asset` are TextMesh Pro dynamic SDF assets generated by `DungeonEntryFonts` (Editor) from the unchanged Nanum Gothic source files in `Assets/01.Scripts/06.UI/Hud/Fonts/NanumGothic/Fonts/` (SIL Open Font License 1.1, see `NanumGothic/OFL.txt` there). They are used only by the dungeon entry window and the Rift Guide NPC name tag. The entry-list characters are preloaded; other glyphs populate dynamically. A Player build has not been verified.
