# VFX 프리워밍 대상 등록

요청한 효과를 해당 맵의 준비 대상에 등록한다. 목록 등록 요청만으로 새 로더·풀·네트워크 준비 계약을 구현하거나 전 프로젝트 셰이더를 워밍업하지 않는다.

## 현재 등록 방식 확인

- 저장소 루트 `AGENTS.md`, `docs/unity/MAP_PERFORMANCE_PREPARATION.md` 4장, 대상 VFX 사용 안내를 읽는다. 현재 런타임 구현 상태를 스킬에 고정하지 않는다.
- `rg`로 `prewarm`, `warmup`, `프리워밍`과 관련 카탈로그·로더 참조를 찾는다. ParticleSystem의 `prewarm` 플래그나 특정 효과 풀의 초기 생성을 범용 등록 목록으로 오인하지 않는다.
- 실행용 카탈로그가 있으면 소비 코드와 등록 형식을 확인해 기존 목록에 추가한다. 공용 코드·에셋 변경은 프로젝트 소유권과 씬·에셋 안전 규칙을 따른다.
- 실행용 목록이 없고 준비 문서만 있으면 그 문서에 실제 대상 목록을 추가하고, 자동 실행 미구현을 명시한다. 명시적으로 자동 프리워밍 구현을 요청받았다면 문서 등록만으로 작업을 끝내지 말고 구현 범위를 별도로 다룬다.

## 대상과 의존성 수집

1. 사용자가 지정한 프리팹을 기존 작업·사용 안내에서 확정한다. 형제 번호·난이도 변형의 누락을 확인하되 외부 패키지 전체를 추가하지 않는다.
2. 실제 `.meta` 또는 Unity AssetDatabase로 경로와 GUID를 대조한다. 기존 목록과 GUID 기준으로 중복을 제거한다. 이동·이름 변경은 Unity 에디터에서 수행한다.
3. Unity MCP가 가능하면 `AssetDatabase.GetDependencies(prefabPath, true)`와 Material 조회로 재질·텍스처·셰이더·활성 로컬 키워드를 확인한다. GPU 리소스를 준비하기 위해 실제 재생이나 전투 이벤트를 실행할 필요는 없다. MCP가 없으면 직렬화 참조를 정적으로 추적하고 조회 한계를 기록한다.
4. 프리팹별 의존성 수와 전체 고유 의존성을 구분한다. 재질의 빈 키워드 목록이 전역 조명·그림자·품질 variant가 없다는 의미는 아니다. 메모리나 풀 크기를 파일 개수·maxParticles 합계로 추정하지 않는다.

## 목록에 기록할 것

- 적용 맵·보스·장착 조건, 필수 예고와 장식의 구분.
- 실제 프리팹 경로·GUID, 의존 재질·텍스처 위치, 셰이더와 확인된 키워드.
- 준비해야 할 단계: 예고, 타격, 유지/소멸, 파편, 별도 이동 표현 등 실제 효과 구성.
- 품질·그래픽스 API 조건. 확인하지 못한 variant·PSO는 미검증으로 둔다.
- 초기 생성 수·최대 동시 수·상주 예산과 근거. 측정 전이면 미확정으로 적는다.
- 원본 API에 맞는 정상 종료·취소·풀 반환 조건. 중첩 타격과 잔상 수명도 반영한다.
- 확인 날짜, 검증 수단, 자동 로더 소비 여부와 남은 검증.

무철은 `docs/unity/MUCHEOL_VFX_USAGE.md`에서 번호·루트 재생기·Stop 계약을 확인한다. 새 효과에 무철의 시간·범위·예산을 그대로 적용하지 않는다. 재사용하는 사용 안내에는 목록 링크를 추가하고 기존 목록은 중복 작성하지 않는다.

## 검증과 보고

- 모든 등록 경로가 존재하고 GUID가 실제 에셋과 일치하며 중복이 없는지 확인한다. 실행 카탈로그를 수정했다면 기존 소비 경로가 새 항목을 읽는지도 검증한다.
- 문서만 변경하면 링크·diff를 검사한다. 코드/에셋 변경 시 프로젝트 검증 플레이북에 맞는 컴파일·참조·동작 검증을 추가한다.
- 인스턴스 생성, 시뮬레이션, 실제 렌더/셰이더·PSO 준비, 성능 개선을 각각 구분한다. 대상 등록이나 WarmUp 반환만으로 GPU 워밍업·첫 사용 끊김 해결을 주장하지 않는다.
- ParticleSystem 루프용 `prewarm`을 일회성 효과의 로딩 준비 대신 켜지 않는다. 필수 예고를 준비 실패 때문에 생략하거나 서버 판정을 변경하지 않는다.
- 등록한 효과, 변경 위치, 실제 검증, 미구현/미검증 항목을 간결히 보고한다. 커밋·배포·메시지 발송은 기존 사용자 승인 범위만 따른다. 프로젝트 결과 기록은 AGENTS.md를 따른다.
