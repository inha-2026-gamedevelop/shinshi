# 체험판 부적 효과 45개 — 초기 기준안

> 상태: 게임 설계 기준·미구현·실행 미검증. 수치와 작업명은 사용자 위임의 초기값이며 플레이테스트로 조정한다.

기준: 2026-10-01 · 설계 기준 1.0 · [게임 디자인](../02-game-design.md).

**확정한 범위:** 일반 기술 4개에 보조 2단계·핵심 1단계를 적용한다. 대표 기술은 무사의 넓게 베기·도술사의 불꽃진·신령사의 근접 영물 소환이다. 대표 기술은 단계마다 2개, 나머지 기술은 단계마다 1개로 직업당 15개·총 45개 효과를 만든다. 같은 단계에서 하나만 선택하며 기술당 최대 3개·한 캐릭터 최대 12개 효과가 활성화된다.

**아래 효과명·동작·강화 항목은 사용자 위임으로 채택한 초기 설계다.** 수량·대표 기술의 직접 결정과 구분하며, 모든 수치·레벨별 보너스는 [전투 기준안](combat-design.md#부적-45개-수치-연결)이 기준이다. 기술명은 확정된 기본 행동을 식별하는 표기다. 기본 공격·강림은 별도 부적 선택창이 없고, 신령 동료 공격의 변형은 해당 일반 소환 기술의 부적으로만 연결한다.

새 캐릭터는 부적 없이 기본 기술을 사용할 수 있다. 획득 부적을 신시에서 확률 등록하며 실패 보정은 캐릭터·효과별이다. 등록한 효과는 중복 부적과 정기로 실패 없이 강화한다. 효과 성장 상한은 레벨 5로 확정했다. 스킬별 3단계 선택창과 별도이며 레벨이 올라가도 선택창이 5단계로 늘어나지 않는다. 등록은 50/65/80/100%·시도당 같은 부적 1장과 정기 150이다. 등록한 효과의 레벨 2/3/4/5는 중복 1/1/2/3장·정기 300/600/1000/1600으로 확정 강화한다. 상세 절차와 등록/강화의 구분은 [성장 기준안](growth-economy.md)에 따른다.

## 조합과 확인할 행동

대표 기술의 각 단계 두 후보는 하나만 고른다. 예를 들어 넓게 베기의 빠른 준비·넓은 검세·회전 참격은 자주 쓰는 주변 섬멸 조합이며, 기력 절약·집중 검세·연속 참격은 기력 관리와 집중 타격을 함께 시험하는 조합이다. 동일 단계의 두 핵심 효과를 동시에 적용하지 않는다. 나머지 기술의 단일 후보도 획득·등록 전에는 활성화되지 않는다.

목록은 보조 효과 30개와 핵심 변형 15개다. 원형 변형의 넓은 검세는 반경 +0.5~+0.8m로 대응한다. 집중 검세는 원형 반경을 0.5m 줄이고 피해 보너스를 적용하며, 연속 참격에는 좁은 각도와 두 타격 모두의 피해 보너스를 적용한다. 데이터 값 변경으로 처리하는 항목과 새로운 공격 동작이 필요한 항목을 구분하여 구현량을 산정한다. 피해·범위·쿨다운·기력 감소율과 45개 레벨 1/5 값은 전투 기준안에 채웠다. 레벨 1–5의 추가 보너스는 1/1.15/1.30/1.45/1.60배이며 기본 기술 전체를 다시 곱하지 않는다. 실제 직업별 전투와 조합으로 조정한다.

무적 없는 회피는 유지한다. 반격 부적은 전방 방어와 방어 불가 표시를 우회하지 않는다. 속박진은 보스의 제어 허용 구간에서만 작동한다. 소환물 수·공명 증가량·강림의 소비와 기본 공격 간격이 만드는 총 화력은 별도로 시험해야 한다. 소환물은 월백 주변 인원 집계에서 제외하는 규칙을 유지한다.

효과 선택 전후의 행동 변화·지속 피해 중첩·동일 대상 다중 투사체·소환 갱신·제어 중단·경로와 벽 충돌을 확인한다. 이 목록은 아직 구현·플레이 검증하지 않았다.
