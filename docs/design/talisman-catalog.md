# 검사·마검사 부적 — 30개 정의·세 번째 15개 예약

> 기준일: 2026-10-07. 신규 개편 설계·코드/SO/백엔드 미적용. 효과명·세부 동작·수치는 위임 초기안이며 실제 전투 검증은 하지 않았다.

[게임 디자인](../02-game-design.md) · [전투 수치](combat-design.md#부적-30개-수치-연결) · [모션·저장 이관](character-animation-design.md). 현재 구현 T01~T12의 45효과는 [구 직업 규칙](legacy-class-design.md)에 보존한다.

사용자 확정은 검사·마검사·세 번째 직업 미정이다. 일반 기술 4개에 보조 2단계·핵심 1단계, 단계당 하나·기술당 최대 3개·캐릭터당 최대 12개 활성 구조를 유지한다. 대표 기술은 검사 넓게 베기와 마검사 화염검진으로 제안한다. 대표는 단계당 2후보로 6개, 나머지 세 기술은 단계당 1후보로 9개다. 현재 정의는 **30개(보조 20·핵심 10)**, 세 번째 예약 15개를 합친 최종 목표는 45개다. 예약에는 이름·효과 ID·수치를 부여하지 않는다.

`KS01~04`·`MK01~04`와 아래 효과 코드는 **문서용**이다. 현재 API/SQL의 `Tnn-tierChoice` ID와 호환되지 않으므로 요청값으로 보내거나 기존 등록 진도를 덮어쓰지 않는다. 실제 채번·카드/진도/조합 이관은 별도 구현 게이트다.

등록은 같은 부적 1장+정기 150, 효과별 실패 보정 50/65/80/100%를 유지한다. 등록 Lv1에서 Lv2/3/4/5로 올릴 때 중복 1/1/2/3장과 정기 300/600/1000/1600을 소모하며 확정 성장한다. 추가 보너스 배율은 1/1.15/1.30/1.45/1.60이다. 조합은 신시에서만 바꾸고 출정 때 잠근다. 선택 3단계와 성장 5레벨은 별개이며 기본 공격은 부적창 밖이다. 부적 없이 기본 기술을 쓸 수 있다. [성장 기준안](growth-economy.md)의 경제 규칙을 따른다.

## 조합·공급·검증

핵심 교체를 정한 뒤 보조를 적용한다. KS01 빠른 준비·넓은 검세·회전 참격은 주위 섬멸, 기력 절약·집중 검세·연속 참격은 집중 타격의 시험 조합이다. MK02의 반경/피해 보조는 지속·단일 폭발·잔불에 모두 적용한다. 자세한 합산·회차·범위는 전투 기준안의 표 하나를 기준으로 삼는다.

신규 드롭 설계는 플레이 중인 확정 직업의 15효과를 같은 가중치 1로 고른다. 검사/마검사 사이를 섞지 않고 미정 세 번째의 15자리는 드롭 목록에 넣지 않는다. 현재 구현의 구 45카드와 새 문서 ID를 한 후보 풀에 합치지 않는다. 이 요구의 실행 적용은 저장 데이터·보상 콘텐츠 이관 후다.

정적 확인은 30개 고유 ID, 직업별 15, 대표 6/나머지 9, 보조 20/핵심 10, 모든 행의 전투 수치 연결이다. 기능 확인은 기본 형태와 대표 기술 8조합씩, 비대표 기술 적용/미적용, 최대 12효과·같은 단계 중복 거절, 벽 앞 돌진/투사체, 후속 타격 취소, 화염검진 8회·단일/잔불 폭발, 보스 이동 금지다. 실제 조합·DPS·모션/VFX·M2/M3는 미검증이다.
