# 검사·마검사·궁수 부적 — 45개 정의

> 구현 상태(2026-10-08): 검사·마검사·궁수의 서버 전투·부적·백엔드 계약을 추가했고, 기존 직업과 함께 총 24기술·90효과를 유지한다. 세부 구현·과거 자동 시험과 남은 검증은 [세 직업 구현과 검증](../05-implementation-roadmap.md#2026-10-08-세-직업-구현과-검증)을 따른다. 신규 직업 기본 개방·실제 전투 연결·재생·다인 플레이 완료를 뜻하지 않는다.

> 기준일: 2026-10-08. 신규 개편 설계의 45효과는 코드/SO/백엔드에 구현됨. 문서 ID KS/MK/AR와 런타임 T13~T24를 구분하며 구 진도 이관은 미적용. 효과명·세부 동작·수치는 위임 초기안이며 실제 전투 검증은 하지 않았다.

[게임 디자인](../02-game-design.md) · [전투 수치](combat-design.md#부적-45개-수치-연결) · [모션·저장 이관](character-animation-design.md). 구 구현 T01~T12의 45효과는 [구 직업 규칙](legacy-class-design.md)에 보존한다. 2026-10-08 후속 구현은 신규 효과를 T13~T24로 추가해 런타임 총 90효과가 공존한다. 아래 KS/MK/AR은 문서용 코드이며 실제 채번과 검증 범위는 [로드맵](../05-implementation-roadmap.md#2026-10-08-세-직업-구현과-검증)을 따른다.

사용자 확정은 검사·마검사·궁수다(궁수 2026-10-08). 일반 기술 4개에 보조 2단계·핵심 1단계, 단계당 하나·기술당 최대 3개·캐릭터당 최대 12개 활성 구조를 유지한다. 대표 기술은 검사 넓게 베기·마검사 화염검진·궁수 관통시위다. 대표는 단계당 2후보로 6개, 나머지 세 기술은 단계당 1후보로 9개다. 총 **45개(보조 30·핵심 15)**의 세부 효과는 위임 초기안이며 실전 미검증이다.

`KS01~04`·`MK01~04`·`AR01~04`와 효과 코드는 **문서용**이다. 현재 API/SQL의 `Tnn-tierChoice` ID와 호환되지 않으므로 요청값으로 보내거나 기존 등록 진도를 덮어쓰지 않는다. 실제 채번·카드/진도/조합 이관은 별도 구현 게이트다.

등록은 같은 부적 1장+정기 150, 효과별 실패 보정 50/65/80/100%를 유지한다. 등록 Lv1에서 Lv2/3/4/5로 올릴 때 중복 1/1/2/3장과 정기 300/600/1000/1600을 소모하며 확정 성장한다. 추가 보너스 배율은 1/1.15/1.30/1.45/1.60이다. 조합은 신시에서만 바꾸고 출정 때 잠근다. 선택 3단계와 성장 5레벨은 별개이며 기본 공격은 부적창 밖이다. 부적 없이 기본 기술을 쓸 수 있다. [성장 기준안](growth-economy.md)의 경제 규칙을 따른다.

## 궁수 · AR01~04

> 궁수 속성형 개편(2026-10-15): 효과 ID와 저장 데이터는 바꾸지 않았다. AR01(T21)은 Q 얼음 부여, AR02(T22)는 W 바람 부여, AR04(T24)는 E 불 부여, 대표 AR03(T23)은 R 속성 폭발에 붙는다. 기력·쿨다운 보조(T21-1A, T22-1A, T23-1A, T23-1B, T24-1A)와 T23-2B의 피해 +15%만 동작한다. 나머지 9개(T21-2A/3A, T22-2A/3A, T23-2A/3A/3B, T24-2A/3A)는 화살 형태(사거리·폭·관통·후속 화살·후퇴·부채)를 바꾸는 효과라 서버가 버리며 재설계가 필요하다. 상세는 [궁수 기준안](archer-design.md#3-특성-기존-부적-구조의-15효과).

[궁수 특성 표](archer-design.md#3-특성-기존-부적-구조의-15효과)에 15개 고유 효과와 Lv1→5 수치, 쌍연/관통/산개 중복 규칙을 함께 정의한다. AR01 속사 3개·AR02 후퇴사격 3개·AR03 관통시위 6개·AR04 산개사격 3개다. 사냥(AR03 1B/2A/3A)과 저격(1A/2B/3B)은 시험 조합이며 고정 우열을 보장하지 않는다. 별도 패시브 트리·스택·소환 자원은 없다.

## 조합·공급·검증

핵심 교체를 정한 뒤 보조를 적용한다. KS01 빠른 준비·넓은 검세·회전 참격은 주위 섬멸, 기력 절약·집중 검세·연속 참격은 집중 타격의 시험 조합이다. MK02의 반경/피해 보조는 지속·단일 폭발·잔불에 모두 적용한다. 자세한 합산·회차·범위는 전투 기준안의 표 하나를 기준으로 삼는다.

신규 드롭 설계는 플레이 중인 확정 직업의 15효과를 같은 가중치 1로 고른다. 검사/마검사/궁수 사이를 섞지 않는다. 궁수 AR 15개도 신규 설계 목록에 포함하지만 실제 드롭 공개는 이관 뒤다. 현재 구현의 구 45카드와 새 문서 ID를 한 후보 풀에 합치지 않는다. 이 요구의 실행 적용은 저장 데이터·보상 콘텐츠 이관 후다.

정적 확인은 이 문서 KS/MK 30개와 궁수 기준안 AR 15개의 합계 45개 고유 ID, 직업별 15, 대표 6/나머지 9, 보조 30/핵심 15, 모든 행의 전투 수치 연결이다. 기능 확인은 기본 형태와 대표 기술 8조합씩, 비대표 기술 적용/미적용, 최대 12효과·같은 단계 중복 거절, 벽 앞 돌진/투사체, 후속 타격 취소, 화염검진 8회·단일/잔불 폭발, 보스 이동 금지다. 실제 조합·DPS·모션/VFX·M2/M3는 미검증이다.
