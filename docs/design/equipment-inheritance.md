## 계승 규칙

- 모든 장비의 강화 상한은 25강이다.
- 제작은 보스 재료만 소모해 새 장비를 만든다. 원래 장비는 제작에서 사라지지 않는다.
- 계승은 같은 캐릭터가 가진 같은 부위의 다른 장비에만 진행하고 정기를 지불하며 원본을 소모한다. 비용은 같은 등급 500정기·상위 등급 1,500정기다.
- 같은 등급 원본 0강, 아래 대상 조건 위반, 계승 뒤 공격·생명·방어가 원본보다 낮아지는 경우는 비용·원본을 소모하지 않고 거절한다. 원본 잠금·착용 처리는 [성장·경제 기준안](growth-economy.md) 6장을 따른다.
- 같은 등급 계승은 원본 단계를 그대로 옮긴다. 상위 등급 계승만 위 환산표를 쓴다.
- 상위 계승은 원본 17강 이상이며 바로 한 등급 위로만 허용한다. 전설 원본은 같은 등급 계승만 가능하다. 일반→희귀→영웅→전설을 순서대로 진행한다. 아래 등급 계승이나 등급 건너뛰기는 허용하지 않는다.
- 새 대상은 강화 0단계이며 착용을 해제한 장비로 제한한다. 계승 확인창에 원본 소모, 대상 등급/결과 단계, 정기 비용과 실제 능력치 전후를 보여 준다.
- 실패 보정은 캐릭터·부위·현재 강화 단계별 공유다. 원본 보정을 대상 단계로 복사하거나 합산하지 않고, 결과 단계에 이미 있는 해당 캐릭터/부위 기록을 사용한다. 계승 자체는 확정 성공이다.

## 능력치 연결과 정적 계산

등급별 기본 장비 능력치는 이전 등급의 1.35배, 강화 배율은 `1 + 0.04 × 강화 단계`로 시작한다. 상위 계승 후 장비 능력치의 비율은 `1.35 × (1 + 0.04 × 결과 단계) / (1 + 0.04 × 원본 단계)`다.

| 원본→결과 | 계승 전 대비 해당 장비 능력치 |
|---|---:|
| 17→10 | +12.50% |
| 18→11 | +13.02% |
| 19→12 | +13.52% |
| 20→13 | +14.00% |
| 21→14 | +14.46% |
| 22→15 | +14.89% |
| 23→16 | +15.31% |
| 24→18 | +18.47% |
| 25→20 | +21.50% |

강화 숫자가 내려가도 제작 장비의 공격·생명·방어가 올라가는 것을 산술 확인했다. 장신구 고정 치명 옵션은 유지되며 이 배율을 곱하지 않는다. 이 비율은 캐릭터 전체 화력 증가량이나 플레이 검증 결과가 아니다. 증가 폭·제작/계승 비용·보스 난이도는 실제 전투에서 조정한다.
