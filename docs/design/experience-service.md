# 생활·협동·경매·이야기·체험판 경험 기본안

> 상태: 게임 설계 기준·미구현·실행 미검증. 수치와 작업명은 사용자 위임의 초기값이며 플레이테스트로 조정한다.

2026-10-01. [기획서](../02-game-design.md), [생활·수련 요약](life-training.md), [세계관·서사](world-and-narrative.md)을 연결하는 초기 기획 기본안이다. 사용자의 “나머지 기획적인 것은 적정치로 넣기” 요청에 따라 남은 동작·수치를 채웠다. 기존 사용자 결정은 유지하고, 새로 채운 값은 실제 플레이로 조정한다. 구현·성능·배포 검증이 끝난 상태는 아니다.

2026-10-07 직업 개편은 [캐릭터·애니메이션 개편](character-animation-design.md)을 따른다. 검사·마검사8기술/30효과가 현행 설계이고 미정 세 번째4기술/15효과는 최종3직업 목표의 예약이다. P09 외형·커스터마이징은 유지한다. 구신령사 동료/공명/Z/X/C와 과거 실행 증거는 [기존 직업 설계](legacy-class-design.md)로 보존하며 새 직업의 HUD·전투 구현 완료로 취급하지 않는다.

## 1. 생활 구역과 행동력

| 항목 | 적용 기본안 |
|---|---|
| 장소 | 신시 인근 약초밭. 토벌 전장과 분리된 생활 구역 |
| 구역 인원 | 한 구역 최대 8명. 가득 차면 다른 구역을 안내 |
| 약초 노드 | 12개, 노드 간 이동 동선을 두고 네 묶음으로 배치 |
| 상호작용 | 노드 1.5m 안에서 시작, 3초간 채집. 이동·취소·구역 이탈 시 취소 |
| 선점 | 먼저 시작한 사람 한 명만 채집. 선점 중 다른 유저에게 사용 중 표시 |
| 획득·재생 | 완료 때 약초 2개. 완료 뒤 60초 후 해당 구역의 노드 재생 |
| 생활 도구 | 체험판은 별도 소모 도구 없이 기본 채집 도구 사용 |
| 행동력 | 계정 상한 100, 완료당 2 소모, 5분마다 1 회복. 미접속 시간 반영 |
| 회복 초과 | 상한을 넘는 회복은 저장하지 않음. 상한에서 소비하면 새 5분 주기 시작 |
| 구역 변경 | 구역별 공용 노드 상태를 유지. 다시 들어와도 이미 소모한 행동력·재료는 되돌리지 않음 |

시작할 때 사용 가능한 행동력 2를 예약하고 실제 차감은 채집 완료·약초 지급과 함께 한다. 약초 보관 여유가 2개 미만(품목 상한 9,999)이면 비용 없이 시작을 거절한다. 계정당 채집 선점은 한 개만 허용한다. 취소하면 예약과 선점을 즉시 해제하며 행동력을 잃지 않는다. 연결이 끊기면 5초 뒤 선점·예약을 해제한다. 완료되지 않은 선점은 시작 10초 뒤에도 해제한다. 완료 결과는 한 번만 지급하고, 완료 뒤 연결 종료·재접속으로 재료가 다시 지급되지 않는다.

처음 만든 계정은 행동력 100으로 시작한다. 캐릭터 추가·삭제·재생성으로 행동력을 다시 채우지 않는다. 가득 찬 상태에서 50회 채집으로 약초 100개를 얻으며, 소형 20개 또는 대형 8개와 약초 4개가 남는다. 실제 시간은 이동·공용 노드 경쟁·회복을 포함해 측정한다.

## 2. 물약 제작·지참·사용

| 물약 | 제작 | 회복 | 재사용 |
|---|---|---|---|
| 소형 | 같은 약초 5개 → 1개 | 최대 체력 30% | 두 종류 공용 10초 |
| 대형 | 같은 약초 12개 → 1개 | 최대 체력 50% | 두 종류 공용 10초 |

추가 정기·거래 재화 제작 비용은 두지 않는다. 신시 의술 담당에게 제작하며, 수량 선택 뒤 재료 차감과 완제품 지급을 한 번에 처리한다. 제작 동작은 1초이며 대량 제작은 선택한 수량을 한 번에 정산한다. 선택 수량은 약초 잔량과 완제품 스택 상한 999 안으로 제한한다. 제작에 실패 확률은 없다.

- 물약 완제품은 계정 공동 재고다. 출정 준비에서 소형·대형 지참 수량을 정하고 공동 재고에서 예약한다.
- 일반전과 보스전 모두 가용 재고 안에서 원하는 수량을 지참한다. 일반전은 별도 사용 횟수 상한이 없고, 보스전은 두 종류 합산 **사용 9회**로 제한한다. 지참 수량과 사용 상한을 구분한다.
- 사용 승인 때 물약 1개·출정 사용 횟수를 차감하고 즉시 회복한다. 0.35초의 표시 동작 동안 이동은 가능하며 무적은 없다. 최대 체력을 넘는 회복은 버린다.
- 사망·제어로 행동 불가하거나 체력이 이미 가득 차 있으면 사용하지 않는다. 실패한 사용 입력은 물약·횟수·재사용 시간을 소모하지 않는다.
- 부활·재접속 때 남은 지참량, 누적 사용 횟수, 남은 재사용 시간을 유지한다. 소형·대형을 바꿔도 공용 재사용과 보스 합산 9회는 이어진다.
- 정상 귀환·실패·중도 포기 때 미사용 예약분을 모두 공동 재고에 돌려놓는다. 사용한 물약은 실패 보상 보존 규칙으로 복구하지 않는다.
- 한 계정은 동시에 한 캐릭터만 출정한다. 예약된 물약을 다른 캐릭터나 후속 유저 경매장에서 다시 사용할 수 없다.

신규 캐릭터에는 기본 6부위 장비와 캐릭터 귀속 정기 500을 한 번 지급한다. 장비 등급·능력치는 장비 기본안이 기준이다. 계정 최초 시작 때만 거래 불가 소형 물약 9개를 지급한다. 추가 캐릭터는 계정 공동 재고를 사용하며, 삭제·재생성으로 초기 물약을 반복 공급하지 않는다.

체험판은 희귀 6부위 지급이라는 기존 결정을 유지한다. 시작 강화 단계는 최신 계승·성장 기본안이 기준이다. 체험판 최초 시작 때 소형 9개·대형 9개를 계정에 한 번 지급한다. 정식 최초 소형 9개에 더하지 않는 합계다. 이 지원 물약은 거래 불가이며 재시작·추가 캐릭터로 반복 지급하지 않는다. 배포 버전이나 계정 삭제로 초기 지원을 다시 얻는 경로는 출시 전 확인한다.

## 3. 방 목록·준비·출정

공개 방은 방 이름, 일반전/보스, 지역·난이도, 현재 인원/4, 직업 구성, 준비 상태, 비밀번호 유무를 보여 준다. 전투 종류·지역·난이도와 빈자리로 필터링한다. 직접 초대와 공개 방 입장은 제공하며 자동 매칭을 추가하지 않는다. 직업 중복은 제한하지 않는다.

참가자는 모두 해당 전장을 해금해야 준비할 수 있다. 보스전은 계정 티켓 1장과 지참 물약을 확인한다. 장비·수련·부적·물약 변경은 준비 상태를 해제한다. 전원 준비 뒤 방장이 출정을 시작하며 3초 카운트다운을 보여 준다.

준비 중 방장이 나가면 가장 먼저 들어온 접속 참가자에게 방장 권한을 넘기고, 남은 참가자가 없으면 방을 닫는다. 전투 중에도 방 관리 권한만 같은 방식으로 넘기며 전투·보상 진행을 초기화하지 않는다. 전투 시작 이후 신규 참가자를 받지 않는다.

출정 준비와 전장 연결 동안 티켓·물약을 예약하고 전투 시작이 확정될 때 티켓을 소비한다. 시작 전에 취소·연결 실패·자격 변경이 발생하면 예약을 풀고 티켓·물약을 전부 돌려준다. 한 참가자라도 전장 준비에 실패하면 출정을 시작하지 않고 방으로 돌아온다.

플레이어가 스스로 전투를 포기하거나 일반적인 연결 종료로 빠지면 기존 실패 정산을 적용한다. 이미 전투가 시작된 보스 티켓은 반환하지 않는다. 서비스 장애로 전투 자체가 종료되고 재개할 수 없는 것이 확인되면 취소된 출정으로 처리하여 소모 티켓과 해당 출정에서 사용한 물약을 복구하고, 이미 확정 지급된 전리품은 중복 지급하지 않는다. 플레이어 개인 연결 종료를 서비스 장애로 취급하지 않는다. 일반전 장애 취소 때 출정 원장에 쌓인 미정산 추가 정기의 지급률(100%·50%·0%)은 미정이며 확인이 필요하다. 완료한 웨이브의 기본 정기·정련편과 확보한 부적·티켓은 보존한다.

## 4. 재접속·보상 자격·저장 경험

재접속 유예는 연결 종료부터 120초다. 원래 참가자만 복귀하며 기존 체력·사망·기력·공명·물약·쿨다운 상태를 이어받는다. 접속이 끊긴 캐릭터도 전장에 남아 피격 가능하고 사망 판정에 포함된다. 미접속 중에는 수동 부활·물약·공격 입력이 발생하지 않는다. 유예가 끝나면 이탈로 정산하며 해당 출정에 다시 들어가지 않는다.

보스 처치 순간 원래 참가자이며 아직 유예 안에 있거나 접속한 사람은 사망 여부와 무관하게 확정 기본 보상과 개인 재료 판정을 받는다. 명시적으로 포기했거나 120초를 넘겨 이탈로 정산된 사람은 이후 처치 보상을 받지 않는다. 미접속자는 지급 내역을 다음 접속 때 확인한다. 기본 보상 자격과 경매 분배 자격은 별도로 판단한다.

개별 포기는 파티 전체 포기를 뜻하지 않는다. 남은 참가자는 같은 출정 인원 기준 난이도로 계속 싸운다. 보스 전원 사망은 공용 부활이 남아 있어도 즉시 실패다. 일반전은 무한 부활과 제한 시간 규칙을 유지한다. 전원 명시적 포기 또는 복귀 가능한 참가자 전원의 120초 유예 종료로 출정을 마감한다.

공동 보관 범위는 이야기·지역/보스 해금, 거래 재화, 티켓, 제작/생활 재료, 물약, 아직 등록하지 않은 부적이다. 장비·정기·수련·등록한 부적 효과/레벨은 캐릭터별이다. 미등록 부적을 창고로 옮겨도 효과를 습득한 것으로 처리하지 않는다. 장비 계승이나 캐릭터 삭제로 다른 캐릭터의 성장에 투자 단계를 복사하지 않는다.

저장 기준은 캐릭터 생성·수련/재분배·장비 제작/강화/계승·부적 등록/강화·물약 제작·채집 완료·시장 거래·티켓 소비·전리품 확보·정산 완료다. 재화 차감과 결과 지급이 함께 확정되고, 같은 결과를 재접속으로 두 번 받지 않는다. 전투 상태는 30초마다 복귀를 위한 진행 상태를 남기는 기준으로 설계한다. 실제 저장·복구 방식은 [기술 설계](../03-technical-design.md)를 따른다. 방장 권한 이전은 데디케이티드 서버의 판정 권위를 이전하지 않는다. 전투 상태 복구에 실패하면 확인된 서비스 장애 취소 규칙을 사용한다.

화면에는 저장 중/완료/재시도 중을 짧게 표시한다. 이미 확정된 성장·정산을 보여 준 뒤 재접속으로 이전 상태로 돌아가지 않는지 확인한다. 체험판은 이전 테스트 계정의 데이터 형식과 호환을 보장하지 않으며, 테스트 초기화가 필요하면 참가 안내에 사전 표시한다.

## 5. 보스 처치 후 파티 경매

보스 기본 정기·엽전과 개인 재료 지급을 확정한 뒤 파티 경매를 시작한다. 잔액 0으로 들어온 사람도 성공 기본 엽전으로 최저가 입찰을 할 수 있다. 희귀 재료는 기존 확률 판정으로 나온 것만 경매에 올리고, 일반 보스 재료의 개인 확률 지급과 분리한다. 낙찰 재료는 장신구 제작에 사용한다.

| 항목 | 적용 기본안 |
|---|---|
| 최저가 | 품목(희귀 장신구 재료 1개)당 엽전 100 |
| 입찰 | 첫 입찰은 100 이상, 이후 직전 최고가보다 최소 10 증가, 정수 단위 |
| 기본 시간 | 품목당 30초 |
| 막판 입찰 | 남은 시간 10초 미만에 유효 입찰이 접수되면 남은 시간을 10초로 연장 |
| 시간 상한 | 품목당 최초 시작부터 120초, 상한 이후 연장 없음 |
| 품목 순서 | 현재 규칙은 처치당 최대 1품목. 품목이 여럿이면 출현 목록 순서대로 하나씩 진행 |
| 자금 | 최고 입찰금 예약. 더 높은 입찰이 접수되면 이전 예약 해제 |
| 철회 | 확정 입찰은 철회 불가 |
| 동시 입찰 | 먼저 접수된 유효 입찰을 적용. 뒤 입찰은 새 최고가·잔액 기준 재확인 |
| 수수료 | 파티 경매 0% |

각 품목이 열릴 때 접속한 원래 참가자만 그 품목에 입찰할 수 있다. 도중에 복귀한 참가자는 다음 품목부터 참여한다. 연결이 끊긴 동안 새 입찰은 할 수 없지만 이미 접수한 입찰은 유지한다. 최고 입찰자가 끊겨도 낙찰되면 예약금으로 정산하고 재료를 계정 보관함에 지급한다.

분배 대상은 해당 품목 시작 때 접속 자격이 있었고 종료 때도 접속 중인 참가자 중 낙찰자를 제외한 사람이다. 낙찰금 ÷ 대상 인원을 내림한 정수로 균등 지급하며 나누어지지 않는 잔액은 소모한다. 분배 대상이 없으면 낙찰금 전부를 소모한다. 미접속자에게 분배금을 예약해 주지 않는다.

솔로 또는 한 명만 접속한 상황은 동일 확률로 재료가 나오며 최저가 100으로 구매한다. 구매 대금은 소모한다. 단독 모드는 100 고정 구매 한 번만 받고 구매 즉시 종료하며, 기본 30초 안에 구매하지 않으면 유찰한다(위임 초기안). 아무도 유효 입찰하지 않으면 재료를 소멸시킨다. 이미 받은 기본/개인 보상을 경매 미참여로 잃지 않는다. 낙찰·분배·유찰 결과는 정산 화면에 남고 한 번만 지급한다.

단독 최저가 구매는 **해당 품목을 열 때 접속 자격자가 한 명인 경우**에 적용한다. 여러 명으로 시작한 경매 도중 접속자가 한 명이 되어도 기존 최고 입찰과 가격은 유지한다. 미접속 최고 입찰자의 예약을 취소하거나 현재 접속자에게 최저가로 덮어 지급하지 않는다. 이는 기존 유효 입찰 유지 규칙을 적용하는 경계 조건이다.

## 6. 후속 유저 경매장

체험판에서는 제공하지 않는다. 보스 파티 경매와 별도의 메뉴로 제공하되 계정 공유 거래 재화 잔액은 같다. 매매는 기존 재화의 이동이며 일반전이나 거래 자체에서 새 거래 재화를 생성하지 않는다.

- 거래 가능: 거래 불가 표시가 없는 생활 재료·제작 물약·미등록 부적, 일반 등급의 강화 0단계 장비.
- 일반 장비는 “일반 등급”으로 해석한다. 희귀·영웅·전설 장비, 강화·계승·착용한 장비는 거래 불가다. 장비는 착용 또는 강화/계승 때 해당 캐릭터에 귀속한다.
- 보스 제작 재료·경매 희귀 재료·티켓·정기·등록한 부적 효과·초기 지원품은 거래 품목에 넣지 않는다.
- 정가 판매를 기본으로 한다. 수량과 개당 가격을 입력하고 등록할 때 실제 품목을 판매 보관에 맡긴다.
- 최소 가격 1, 계정 동시 등록 10건, 등록 기간 24시간. 거래 성사 수수료 5%는 올림 계산하고 판매 대금에서 뺀다. 최종 수령액을 등록 전에 표시한다. 올림 단위(구매 한 건 총액 또는 개당)는 미정이다. 개당 기준이면 가격 1~20은 수수료가 개당 1이라 가격 1의 수령액이 0이 된다.
- 등록 수수료는 없다. 팔리지 않은 물품은 언제든 취소하며 판매 완료분은 취소할 수 없다. 만료·취소 때 미판매 수량을 반환한다.
- 검색은 품목·직업·부적 기술/효과·등급으로 하고 개당 가격순·최신순·수량순으로 정렬한다.
- 구매 때 품목·수량·지불 총액을 확인한다. 재화 차감, 판매 재고 감소, 구매자 지급, 판매자 정산이 함께 확정된다. 이미 팔린 수량을 중복 구매하지 않는다.
- 접속하지 않은 판매자도 판매 대금을 받으며 다음 접속에서 판매 내역을 확인한다. 우편·외부 메시지 발송을 요구하지 않는다.

## 7. 이야기 진행과 NPC 기능

원문의 이름 없는 여우는 여성으로 서술되는 신시의 스승이었으며 산으로 떠난 뒤 스스로 월백이라는 이름을 얻는다. 그녀는 힘·불멸보다 이름·가족·늙어감·다음 세대에게 삶을 남기는 인간의 삶을 동경했다. 월백은 인간이 되고 싶지 않다고 말해도 인간과 단군에게 인정받고 싶었던 과거를 완전히 지우지 못한다. 신시는 여러 인간 세대 동안 유지되었지만 현재는 인간의 나라가 완성되기 전이다. 플레이어는 현재 세대의 신시 주민이자 토벌대 전사로, 스승이 남긴 부적 사용법을 다른 인간 스승에게 이어 배운 사람으로 시작한다. 모든 캐릭터가 월백의 직접 제자였다고 확정하지 않는다.

산귀 정기는 불순하여 정제 없이 쓰면 인간도 변질될 수 있다. 정제법 전체를 관리하던 권한은 단군에게 있었고 월백은 그 핵심 원리를 빼돌린 뒤 산과 산귀에 맞게 다시 만들었다. 목소리는 단순한 힘이나 영생의 약속보다 인정과 의심을 이용해 그녀를 흔들었다. 원문에서 여우인 존재가 인간화 약속을 이루었다거나 처음부터 인간 여성이었다고 바꾸지 않는다.

단군은 인간의 삶을 위협하는 산귀만 토벌한다. 비적대 산귀를 적으로 선택하거나 생활 재료를 위해 처치하는 흐름은 두지 않는다. 단군이 약속을 미룬 실제 속내는 끝까지 공개하지 않는다. 목소리의 “처음부터 뜻이 없었다”는 말은 적대적 주장으로 제시하며 사실 해설로 확정하지 않는다.

| 신시/산 NPC 기본안 | 기능과 표시 |
|---|---|
| 단군 | 토벌의 목적·범위와 주요 이야기 보고. 성장 메뉴의 반복 클릭 담당으로 쓰지 않음 |
| 정제관 서린 — 작업명 | 회수 정기 정제·수련/재분배, 부적 정제·인간용 술식 등록 |
| 장인 담우 — 작업명 | 보스 재료 장비 제작·강화·같은 부위 계승 |
| 의술사 여온 — 작업명 | 약초 채집 안내·소형/대형 물약 제작·생활 구역 진입 |
| 토벌대 길잡이 가람 — 작업명 | 지역 선택·파티 출정·토벌 결과 보고 |
| 산길지기 — 작업명, 비적대 산귀 | 숲의 안전한 길과 여우의 흔적 단서. 중립 대화 표시·공격 대상 제외 |

풍백·우사·운사는 원문 역할을 유지하며 이야기 장면에서 계절·물·하늘의 변화를 알린다. 새 서비스 NPC와 이름은 제작 기본안이며 실제 모델·성우·에셋이 확보되었다는 뜻은 아니다.

### 최종 지역 해금 기본안

1. 신시 안내와 첫 숲 6웨이브 성공으로 폐허를 영구 해금한다.
2. 폐허 6웨이브 성공으로 첫 보스 이지를 해금한다. 첫 보스 작업명은 인간형 산귀 장수 **철각**이다. 인간 영역 공세를 지휘하는 월백 휘하 전투 지휘관으로 둔다.
3. 철각 이지 첫 처치로 철각 하드와 오래된 제단을 영구 해금한다. 철각 이지/하드는 일반/희귀 제작 재료를 제공한다.
4. 제단 6웨이브 출정에 성공할 때마다(최종 웨이브 지휘 산귀 처치 포함) 성공 시점 보상 자격자의 계정에 여우의 흔적 1개를 확정 지급한다. 실패·포기 출정은 흔적을 주지 않는다. 3개를 모으면 월백 결계를 영구 해금하고 이후 더 쌓지 않는다.
5. 흔적 3개와 철각 하드 첫 처치 기록을 모두 가진 계정은 월백 이지에 입장한다. 월백 이지 첫 처치로 월백 하드를 해금한다. 이지/하드는 영웅/전설 재료를 제공한다.

흔적은 계정 진행 항목이며 거래·창고 물품·매회 소모 입장권으로 사용하지 않는다. 월백 결계를 연 뒤에는 흔적을 추가로 요구하지 않고 각 참가자의 공용 보스 티켓 1장을 소비한다. 파티 전원이 해당 해금 조건을 갖추어야 한다. 열린 지역의 일반전은 자유롭게 반복한다.

첫 보스의 정확한 고유 공격과 연출은 후속 제작 콘텐츠다. 체험판에는 철각 전투·폐허·제단을 넣지 않고 숲 1개와 월백 이지 1개로 기존 범위를 유지한다. 체험판은 월백을 미리 해금한 전투 시험이며 정식 이야기 해금 완료로 기록하지 않는다.

### 프롤로그와 월백 전후 장면

체험판 프롤로그는 약 90초로 잡는다. 신시의 토벌 준비 30초 → 과거 스승이 남긴 부적과 조직된 산귀의 단서 30초 → 월백 전투 시험임을 알리는 출정 안내 30초다. 짧은 장면·자막·제한된 카메라 동작으로 구성하며 완성 컷신 대신 자동으로 삭제하는 범위 변경은 하지 않는다.

정식 월백 첫 조우 장면은 45초, 첫 처치 뒤 장면은 60초를 기본 길이로 잡는다. 월백의 자립 명분과 인간 영역 침공의 책임을 함께 보여 주고, 죽은 뒤 남은 기록에서 설명되지 않는 술식과 목소리의 흔적을 찾는다. 단군의 실제 의도나 흑막 정체를 해설로 밝히지 않는다.

월백은 정식 이야기 첫 처치에서 죽는다. 산귀 세력과 이미 퍼진 정제법·부적 기술은 그 죽음으로 사라지지 않는다. 이후 반복 공략은 게임플레이로 취급하며 부활·분신·시간 되돌림을 새 세계관 설정으로 만들지 않는다. 계정의 첫 처치 상태는 보상을 받은 사람마다 기록한다. 이미 첫 처치한 동료가 있어도 아직 보지 않은 사람은 자기 첫 장면을 볼 수 있다. 멀티플레이 장면은 모두 준비하면 진행하며, 이미 본 참가자는 별도 대기한다. 미접속·유예 중 참가자는 기다리지 않으며, 준비하지 않는 참가자에 대한 대기 상한은 미정이다. 반복 장면은 개인 설정으로 자동 건너뛴다. 주요 대사는 기록 화면에서 다시 읽을 수 있다.

## 8. 미술·음향·화면 기본안

2026-10-01 사용자 교정을 반영해 **실사에 가까운 3D 스타일화 판타지**를 목표로 한다. [컨셉아트](concept-art.md)의 큰 형태와 판타지 색감을 기준으로 석재·목재·식생의 자연스러운 균열·마모·이끼·거칠기·PBR 재료 반응과 조명을 함께 유지한다. 스타일화 지정을 평면 파스텔·로우폴리로 자동 해석하지 않는다. 부적·수묵 표현과 전투 가독성 기준은 유지하며 참고 시트의 구조와 재료 특징을 실제 게임 카메라에서 대조한다.

같은 날 사용자가 지정한 [아트 제작 기본 과정](../unity/ART_ASSET_PRODUCTION_WORKFLOW.md)에 따라 모델 작업에는 별도 요청 없이 실제 AO·노멀·거칠기와 셰이더에 맞는 PBR 작업, LOD·충돌 검토와 `Assets/02.Prefab/` 프리팹 구성을 포함한다. 재료·셰이더상 예외는 이유와 실제 확인 결과를 기록한다. ChatGPT 목표 시안은 표현 비교용이며 AO 맵이나 게임 내 구현 증거로 대신하지 않는다.

사람은 약 5.5~6등신, 산귀는 인간형 실루엣에 과장한 팔·뿔·가면 등 원문 특징을 사용한다. 과도한 유혈 표현보다 뒤틀린 형태·소리·흑색 정기로 불안을 전달한다. 월백은 달빛 흰색의 여성형 여우 영물 실루엣과 긴 꼬리 한 개를 초기 외형으로 잡으며, ‘구미호’ 작업명만으로 꼬리 아홉 개를 요구하지 않는다. 캐릭터 비례는 재질·조명 방향과 구분한 기존 기준이다.

기본 색은 먹색·짙은 녹색 지형, 미색/청록 플레이어 효과, 자주색 산귀 술식이다. 적의 공격 위험은 붉은 경계, 방어 불가 공격은 붉은 이중 경계로 구분한다. 검사에게 전방 완전 방어·반격을 부여한다는 의미는 아니다. 황색은 상호작용·주의 안내에 쓴다. 중요한 공격 예고는 색뿐 아니라 채워지는 모양·외곽선·음향으로 구분한다. 겹치는 플레이어·마법 효과는 최대 밝기를 낮추고 적의 위험 예고를 위에 읽히도록 한다. 가리는 나무·구조물은 플레이어 주변에서 투명하게 표현한다.

신시는 장단이 느린 타악·현악, 일반전은 중간 템포 타악, 월백은 낮은 현과 여우불의 날카로운 효과음을 사용한다. 공격 예고음·피격음·물약/부활·입찰 갱신은 서로 다른 짧은 음으로 구분한다. 특정 기존 음원·유료 에셋 확보를 전제로 하지 않는다.

| 화면 | 배치·내용 |
|---|---|
| 캐릭터 선택 | 검사·마검사/캐릭터별 성장, 계정 공유 항목 안내, 초기 지원의 재지급 여부. 미정 직업은 구현 이관 전 선택/생성 대상으로 열지 않음 |

## 9. 외부 체험판 목표와 실제 남은 의존

최종 구성은 첫 보스/월백 각각 이지·하드인 2종·4전투다. 외부 체험판의 최종 목표는 세 직업, 숲1개, 월백 이지1개, 1~4인, 성장·보스 파티 경매·약초 채집·물약 제작을 연결하는 것이다. 현재 검사·마검사만 설계했고 세 번째는 미정이므로 두 직업 시험 빌드를 최종 세 직업 체험판 완료로 보고하지 않는다. 유저 경매장은 후속이다. 월백2페이즈는 다른 담당자가 작성 중인 입력을 받아 붙이며 이 문서가 새 패턴을 대신 확정하지 않는다.

진욱은 UI·성장·맵, 기웅은 보스·몬스터·프롤로그·컷신, 민성은 나머지를 담당한다. 3인·2주 외부 체험판 목표일은 2026-10-15다. 중간 점검 시점과 확인할 결과는 [구현 로드맵](../05-implementation-roadmap.md) 4장을 기준으로 한다. 가용 시간과 실제 완료 상태를 확인한 보장 일정은 아니다.

성능 목표는 1920×1080에서 1~4인 전투 평균60fps 이상, 측정 프레임 시간95백분위25ms 이하로 잡는다. 검사/마검사 동일·혼합4인, 최대 전장 몬스터24체, 장판/검파/부적 변형의 효과 중첩과 P09 외형 부하를 측정한다. 세 번째 직업 부하는 확정 후 추가한다. 구신령사4명·동료8체 시나리오는 구구현 회귀 부하로 남기며 새 직업의 합격 증거로 재사용하지 않는다. 목표 시험 하드웨어·그래픽 설정·운영체제와 실제 배포 환경은 팀이 제공해야 하는 외부 조건이다. 특정 PC·서버·에셋을 이미 보유하거나 검사했다고 기록하지 않는다.

초기 체험자는8명으로 잡고 확정 두 직업의 솔로·같은 직업4인·혼합4인과 서로 다른 두 네트워크 환경을 먼저 시험한다. 최종 세 직업 검증은 미정 직업 확정/구현 뒤 추가하고 최소20회 출정·일반전 완료 시간 중앙값5~6분·첫 성장 변화 이해도8명 중6명 이상·보스 성공10~15분 목표를 확인한다. 90분 연속 플레이와 의도적인 재접속10회를 포함한다. 출정 티켓·물약·채집·낙찰/분배의 중복 지급 또는 음수 재고0건, 전투를 끝낼 수 없는 오류0건을 외부 배포 기준으로 둔다. 실제 테스트 결과는 별도 기록한다.

남은 것은 숫자 결정 반복이 아니라 실제 콘텐츠·기술·검증 입력이다.

- 담당자가 설계 중인 월백 2페이즈 문서와 제작 결과.
- 미정 세 번째 직업의 전투 역할·기술·부적·클립과 새 직업 코드/데이터 이관 검증.
- 팀의 실제 가용 시간, 재사용 가능한 캐릭터/몬스터/맵/애니메이션/VFX/UI/음향 자산과 이용 권한.
- 목표 시험 PC·그래픽 설정, 서버 호스팅·접속 주소·배포 경로와 참가 계정 운영 조건.
- 위 기본안으로 제작한 뒤의 솔로/협동 난이도·성장 속도·생활 공급·경매 경제·성능/재접속 실측.

원문 세계관의 미공개 의도·흑막 정체는 의도된 설정이며 남은 업무로 밝히지 않는다. 이 문서의 기본안은 원문의 제목이나 원본 텍스트를 바꾸지 않는다.
