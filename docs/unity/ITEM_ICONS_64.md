# 아이템 64픽셀 아이콘

## 파일과 연결 범위

`Assets/01.Scripts/05.Art/UI/Icons/Textures/Items64/T_Item64_*.png`는 실제 64×64 RGBA PNG 45종이다. 철·금·옥 장비, 보스 파편과 경매용 영옥, 한지와 기술 상징의 부적을 사용한다.

| 원화 | 연결할 정의 | 구분 방식 |
|---|---:|---|
| 장비 6부위 | 30 | 등급은 기존 아이템 칸 테두리와 색 사용 |
| 재화·재료·소모품 15종 | 15 | 품목별 독립 그림 |
| 부적 24기술 | 90 | 기술 그림 + `1A`·`3B` 등의 단계·선택 배지 |

135개 정의에 그림 135장을 별도로 만든 것은 아니다. 신규 아이템·밸런스 데이터는 추가하지 않는다. 부적은 현행 직업과 구직업 보존 정의를 모두 포함한다.

## 적용 도구

편집 모드에서 `Shinshi/UI/아이템 64px 전체 적용`을 실행한다. `ItemIcon64Builder`는 다음을 순서대로 처리한다.

1. PNG를 Single Sprite, 알파 유지, 밉맵 끔, Read/Write 끔, 비압축, 최대 64px로 설정한다.
2. 기존 `UiIconLibrary.asset`의 다른 항목을 보존하면서 135개 정의와 장비 공통 키 6개를 연결한다.
3. `PF_ItemSlot`, `PF_ItemSlot_Flat`에 부적 구분 배지를 연결한다.
4. 강화·옵션 재설정 프리팹을 새 아이콘으로 재생성한다. 현재 열린 씬은 저장하지 않는다.
5. 정의별 Sprite 참조·임포트 설정과 두 아이템 칸의 부적→일반 품목→빈 칸 전환을 검사한다.

프리팹 재생성 전에 해당 프리팹의 별도 수동 변경이 있는지 비교한다. 프로젝트에 저장된 45 PNG만으로도 적용할 수 있으며 제작자의 고해상도 원본은 필수 의존성이 아니다.

## 확인 상태 — 2026-10-15

- 완료: 45 PNG의 실제 크기 64×64, RGBA·투명 영역 확인. 135개 정의→45개 그림 정적 대응 누락 0. 어두운 배경에서 64픽셀 크기의 전체 그림 시각 검수.
- Unity Sprite 설정과 라이브러리·프리팹 연결 완료. `ApplyAll()`과 `Verify()` 실제 실행 통과. `.meta` 누락 0.
- 기본·Flat 아이템 칸에 전체 135개 정의를 각각 적용한 270회 표시 확인과 빈 칸 재사용 2회 통과. 아이콘·수량·잠금·부적 단계/선택 배지를 함께 확인했다.
- 강화·옵션 재설정 개발 씬의 Play Mode 화면 캡처 확인. 별도 PreviewScene에서 실제 Flat 프리팹 45개를 렌더해 시각 검수했다.
- 관련 EditMode 테스트 55개 통과(강화 규칙, 옵션 표시 규칙, 인벤토리 페이지). 대상 프리팹 4개의 Missing Script는 0.
- 다른 동시 작업의 NavMesh 무한대 좌표 오류와 Missing Script 경고가 콘솔에 있어 전체 콘솔 오류 0으로 보고하지 않는다. 이 아이콘 변경에서 해당 코드를 실행하거나 수정하지 않았다.
- 실제 서버 접속·아이템 획득·재화 차감·다인 접속은 이번 UI 검증 범위가 아니다.
