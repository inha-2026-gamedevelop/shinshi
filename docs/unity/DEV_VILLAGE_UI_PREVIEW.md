# 마을 개발 씬 UI 조작

대상은 `Assets/00.Scenes/Dev_HUD/Dev_ShinshiVillageQuarterView.unity`다. 루트의 동명 마을 씬과 구분한다. UI 조작 검수용이며 서버에 경제·파티 요청을 보내지 않는다.

## 사용

Play Mode에서 오른쪽 상단 메뉴를 누른다. 우편함과 출정 준비가 추가되어 있으며 인벤토리·경매장·거래·캐릭터 정보·환경설정 창을 연다. 특성 항목은 캐릭터 정보의 수련 요약으로 연결된다.

우편함 메뉴는 `Assets/01.Scripts/05.Art/UI/HudMenuButton/Textures/T_HudMenuButton_IconMail.png`의 은색 봉투 Sprite를 사용한다. 흰색 틴트·비율 유지로 표시하며 메뉴를 재생성해도 같은 Sprite가 연결된다.

| 입력 | 연결 |
|---|---|
| I | 인벤토리 |
| Y | 경매장 |
| M | 우편함 |
| U | 캐릭터 정보 |
| P | 출정 준비 |
| Esc | 확인창 → 열린 창/우클릭 패널 → 메뉴 순서로 처리 |
| 시험용 캐릭터 짧은 우클릭 | 자기 정보 또는 상대의 거래·파티 초대·귓속말·정보 메뉴 |

글자 입력 중에는 기존 `HotkeyRouter`가 단축키를 막는다. 긴 우클릭, 누른 캐릭터와 뗀 캐릭터가 다른 입력, UI 뒤에 가려진 캐릭터에는 상호작용 패널을 열지 않는다.

## 조작 범위

- 인벤토리: 예시 아이템 선택, 툴팁, 카테고리, 정렬, 슬롯 이동과 Alt+클릭 정렬 잠금. 바꾼 배치는 창을 다시 열어도 해당 Play 세션 동안 유지된다. 창고·분해 버튼은 비활성이다.
- 경매장: 검색·직업/등급/품목 필터·정렬·페이지, 품목 상세와 수량, 구매 확인, 판매 수량/가격 입력·검증·등록, 내 등록 취소, 예시 거래 기록.
- 우편함: 14개 예시 우편의 두 페이지, 상세 선택과 첨부 받기. 수령한 항목의 재수령은 막는다.
- 거래: 예시 인벤토리에서 제안 추가/제거, 엽전 입력, 확정/해제, 5초 대기, 수락 확인과 종료. 상대 제안은 고정 예시다.
- 파티 초대: 확인하면 출정 준비를 연다. 이 창에서는 난이도·준비·출정·나가기를 함께 시험한다. 실제 출정은 안내창까지 진행한다.
- 캐릭터 정보: 예시 능력치와 기존 3D 미리보기. 특성 변경이나 장비 장착을 처리하지 않는다.
- 환경설정: 기존 설정 프리팹을 사용한다. 적용하면 그래픽·오디오 설정이 실제 저장된다.
- 귓속말·캐릭터 선택: 서버 연결 또는 해당 개발 씬 안내. 게임 종료: 확인하면 에디터 Play Mode를 종료한다.

모든 경제 데이터와 파티 상태는 Play Mode를 끝내면 사라진다. 실제 서버 구매·우편 지급·두 클라이언트 거래·채팅·출정은 별도 통합 검증 대상이다.

## 구성과 재배치

`VillageUiPreview` 루트가 창·로컬 예시 데이터·단축키를 연결한다. `PlayerInteractionPanelOpener`의 `_previewActions`가 켜진 개발 씬에서만 우클릭 이벤트가 예시 화면으로 전달된다. 기본 네트워크 거래·초대 경로는 유지한다.

편집 모드의 대상 씬에서 `Shinshi > UI > 마을 개발 씬 조작 연결`을 실행하면 해당 루트와 연결을 다시 만든다. **루트 내부의 수동 편집은 재실행 시 대체된다.** 기존 `Release/ShinshiTown`의 창 사본과 설정 프리팹을 사용하며 원본 통합 씬은 저장하지 않는다. 개발 씬 연결을 출시 통합 씬에 그대로 적용하지 않는다.

### 출시 마을과의 구분

캐릭터 정보창의 고정 구 무사 모델은 제거했다. `CharDetailPreviewBinder`는 현재 `NetworkClient.localPlayer`의 서버 외형을 P09 미리보기에 반영하고, 유효한 로컬 캐릭터가 없으면 모델을 숨긴다. 출시 생성 화면의 선택지는 검사·마검사·궁수다. 캐릭터 레벨은 현재 저장 계약에 필드가 없어 HUD·선택 슬롯·출정 표시를 초기 레벨 1로 통일하며 부적 레벨은 변경하지 않는다.

2026-10-10 출시 연결 보완 검증: 관련 EditMode/Play Mode 전환 테스트 235개는 최종 재실행 결과를 합산해 전부 통과했다(전체 235개 실행 후 VFX·모션 관련 124개 재실행). 메뉴의 실제 포인터 클릭·Esc 닫기·설정/확인창, 현재 캐릭터 남녀 미리보기, 19개 전투 상태의 본 움직임, 16개 VFX의 렌더링을 포함한다. 재질 참조 확인에 더해 화면의 오류 셰이더 색상과 무출력을 검사했다. 실제 서버 경제 거래와 다인 접속 전투는 이 테스트 결과에 포함하지 않는다.

`Release/ShinshiTown.unity`의 메뉴 연결은 `Shinshi > UI > Wire Release Town Menu`로 별도 구성한다. 이 도구는 개발 씬의 `VillageUiPreview`를 복사하지 않고 기존 `HotkeyWindowToggle`, 서버용 UI Binder와 `ReleaseMenuActions`를 연결한다. 인벤토리, 경매장, 우편함, 캐릭터 정보, 특성(수련 요약), 출정 준비, 환경설정, 거래 안내, 캐릭터 선택, 종료가 대상이다. 실제 거래 요청은 상대 플레이어 우클릭의 거래하기를 사용한다. 귓속말은 소셜 구현의 `PlayerInteractionPanelOpener`→채팅 입력 경로를 사용한다. 타인 상세의 구현·수용과 개발 미리보기는 별도로 구분한다.

환경설정은 `PF_SettingsWindow`를 사용하며 출시 씬에서는 `HotkeyRouter`로 Esc를 처리한다. 캐릭터 정보 창의 활성 상태가 바뀌면 별도 3D 미리보기 스테이지도 함께 켜고 끈다. 출시 씬 저장은 통합 담당 승인 범위에서만 수행한다.

`ReleaseSceneUiTests`는 저장된 메뉴 대상과 Play Mode 포인터 클릭, 창 닫기, 설정 Esc, 종료/캐릭터 선택 취소를 검사한다. 이 검사는 실제 서버 구매, 우편 수령, 다인 거래와 출정 검증을 대신하지 않는다.

2026-10-10 Unity 6000.4.7f1에서 `ReleaseSceneUiTests`, `HotkeyTests`, `UiBindingRulesTests` 30/30 통과. 출시 마을 Play Mode에서 인벤토리, 경매장, 우편함, 캐릭터 정보, 특성의 포인터 클릭과 Esc 닫기, 캐릭터 미리보기 활성 상태, 환경설정 열기와 Esc, 종료 및 캐릭터 선택 확인창의 취소를 확인했다. 서버 다인 접속 및 배포본 검증은 미실행이다.

## 검증 범위

2026-10-08 Unity 에디터에서 Play Mode 버튼의 EventSystem 클릭 판정, 우클릭 광선 선택, 창/팝업 닫기 순서와 주요 정상·실패 입력을 확인했다. 기존 입력·거래 규칙 EditMode 테스트 26/26 통과. Player 빌드와 실제 서버 다인 연결은 미검증이다. 개발 씬에 국한한 UI 기능 검증이며 네트워크 통합 완료를 뜻하지 않는다.

우편함 아이콘 적용 후 커밋 전 재확인에서는 `PlayerInteractionAndQuickSlotRulesTests`와 `TradeMarketRulesTests`의 EditMode 테스트17/17이 통과했다. 메뉴 아이콘 생성 함수의 화살표·봉투 분기와 봉투 재호출을 확인했고, 기존 `OpenMail` 이벤트도 유지된다. 메뉴 사본의 Unity 카메라 캡처로 은색 봉투 표시를 확인했다. 현재 환경설정 씬의 미저장 작업을 보존해 이번 아이콘 변경에 대한 Play Mode 전환은 수행하지 않았다.
