# 개발 씬 피격 불똥

`DevHitFeedbackSparks`는 개발 씬에서 피격 표현을 비교하는 풀이다. 2026-10-26에 백열 섬광, 잔불, 접점 플래시를 분리했다. 기존 `HitFeedbackDirector`의 생성과 `Burst` 호출은 그대로 사용하므로 히트피드백 씬을 저장하거나 다시 연결할 필요가 없다. 릴리즈 `HitSparkPool`에는 이 변경을 적용하지 않았다.

## 사용과 참조

- 재사용 프리팹: `Assets/02.Prefab/VFX/HitFeedback/PF_DevHitSparks.prefab`.
- 컴포넌트: `Assets/01.Scripts/99.Dev/Combat/DevHitFeedbackSparks.cs` (`Shinshi.Dev`). 프리팹은 개발 씬에서 사용한다.
- 재질과 텍스처: `Assets/01.Scripts/99.Dev/Combat/HitFeedback/Sparks/Materials/M_DevHitSparkSoftCore.mat`, 같은 `Sparks/Textures/T_DevHitSparkSoftCore.png`.
- 셰이더: 기존 `Shinshi/VFX/ReleaseParticle`. 발광 마스크를 가산 합성하며 깊이 검사를 유지한다. 공유 셰이더와 릴리즈 재질은 수정하지 않았다.

`Burst(Vector3 point, Vector3 direction, int count, bool isCritical)`를 확정된 피격 표현 시점에 호출한다. `point`는 월드 공간 접점, `direction`은 공격이 진행한 월드 방향이다. 입자는 몸 안에 묻히지 않도록 그 반대쪽 접촉면 밖과 위쪽으로 튄다. 영벡터와 수직 방향도 허용한다. 피해량과 판정 시점은 이 컴포넌트가 결정하지 않는다. 예고나 서버 시각을 새로 만들지 않으며 네트워크 연결 코드도 추가하지 않았다.

`StopAll()`은 모든 잔상을 즉시 지운다. 비활성화 시에도 같은 정리를 하고, 재활성화 후 기존 풀을 다시 사용한다. 루트의 스케일은 `(1, 1, 1)`을 유지한다. 입자는 월드 공간에서 시뮬레이션하므로 방출 후 루트를 옮겨도 기존 입자는 따라가지 않는다.

## Inspector 조정

| 설정 | 기본값 | 의미 |
|---|---|---|
| `_streakLifetime` | 0.14~0.30초 | 짧게 번쩍이는 흰 선의 수명 |
| `_streakSpeed` | 7~18m/s | 흰 선의 초기 속도 |
| `_streakWidth` | 0.20~0.34m | 부드러운 마스크를 적용하기 전 카드 너비 |
| `_streakStretch` | 0.05 | 속도에 비례하는 선 길이 |
| `_streakRatio` | 0.65 | 전체 입자 중 백열 섬광 비율 |
| `_density` | 2 | 호출자가 요청한 개수의 표현 배율 |
| `_emberLifetime` | 0.28~0.70초 | 작은 잔불이 식는 시간 |
| `_emberSpeed` | 2.5~7.5m/s | 잔불 초기 속도 |
| `_emberWidth` | 0.16~0.30m | 잔불 카드 너비 |
| `_emberGravity` | 1.6 | 잔불 중력 배율 |
| `_streakExposure`, `_emberExposure` | 6, 4 | 재질 HDR 밝기 |
| `_spreadAngle`, `_upBias`, `_drag` | 68도, 0.65, 1.4 | 퍼짐, 상향 성분, 공기 저항 |
| `_criticalWidthScale` | 1.15 | 치명타 너비 배율. 치명타 개수 배율은 기존 피격 프로필이 먼저 적용 |
| `_flashSeconds`, `_flashSize` | 0.08초, 1.1m | 접점 플래시 수명과 카드 크기 |

한 타격의 선과 잔불 합계는 64개를 상한으로 하고 플래시 1개를 별도로 낸다. 풀은 12칸이며 각 칸에 선, 잔불, 플래시 ParticleSystem을 하나씩 둔다. 13번째 중첩 타격은 가장 오래된 칸의 잔상을 지우고 재사용한다. 자연 종료까지 풀 반환을 기다리거나 상시 Update를 돌리지 않는다.

설정은 `Awake`에서 풀에 적용한다. 시간을 포함한 설정을 바꾼 뒤 재생을 다시 시작한다. 기존 씬은 `HitFeedbackDirector`가 `AddComponent`로 생성하므로 코드 기본값을 사용한다. 재사용 프리팹의 Inspector 변경은 그 프리팹 인스턴스에만 적용되며 기존 씬의 자동 생성 인스턴스에 전파되지 않는다.

재질 원본을 직접 바꾸지 않고 초기화 때 두 개를 복제하며 파괴 시 해제한다. 자동 생성 경로는 64x64 선형 RGBA 마스크도 한 번 만들고 GPU 업로드 후 CPU 복사를 버린다. 프리팹은 같은 수식으로 출력한 PNG와 명시적 재질 참조를 사용한다. 텍스처는 선형, Bilinear, Clamp, 무압축, 밉맵 없음이다. 그림자와 AO/PBR, 메시 LOD, 피해 Collider는 사용하지 않는다. 빛나는 미세 입자라 표면 재질의 가림과 반사 표현이 필요하지 않으며, 지형에 튀는 처리는 ParticleSystem의 정적 월드 충돌로 한다.

카메라 거리 40m, FOV 30도, 약 905x408 Game View에서 읽히도록 입자 폭, 밝기와 수명을 조정했다. 11m 근접 촬영본은 기본 게임 시점의 가독성 근거로 사용하지 않는다.

## 준비 대상과 검증

프리워밍 대상과 릴리즈 카탈로그 제외 이유는 [맵 성능 준비의 개발 불똥 항목](MAP_PERFORMANCE_PREPARATION.md#개발-씬-준비-대상---피격-불똥)을 따른다. 풀 초기 생성과 실제 셰이더/PSO 워밍업은 서로 다른 작업이다.

아래 1차 검증은 밀도 1.6과 더 작은 입자 설정의 기록이다. 현재 기본값의 가독성은 뒤의 40m 후속 검증으로 구분한다.

2026-10-26 Unity 6000.4.7f1의 `Dev_ForestPlateauHitFeedback`에서 기존 `ReportHit -> OnPlayerHit -> Burst` 경로로 일반/치명타를 재현했다. 30fps 고정 시간 진행의 실제 Unity 카메라 66프레임 영상을 촬영했다. 비교 영상에서 다른 몬스터는 임시로 숨기고 근접 카메라를 사용했으며 치명타 화면 블러와 줌은 촬영 중에만 껐다. 씬은 저장하지 않았다.

| 주장 | 수준 | 증거 등급 | 실행 수단 | 실제 결과 | 상태 |
|---|---|---:|---|---|---|
| 일반/치명타의 백열 섬광과 잔불 | L2 | 2 | 실제 개발 씬 피격 호출, Unity 카메라 캡처 | 초기 섬광과 후속 잔불 확인 | 완료(검증됨) |
| 중첩, 종료, 재활성화 | L2 | 2 | 같은 런타임 인스턴스의 API 계측 | 0개 요청 0개, 14연속 방출 뒤 204개, 0.8초 시뮬레이션 뒤 0개, 비활성화 뒤 0개, 재활성화 뒤 17개 | 완료(검증됨) |
| 재사용 프리팹 | L2 | 2 | 프리팹 생성, 의존성 조회, 런타임 Instantiate/Burst | 재질/텍스처 연결, 한 번 방출 시 17개 | 완료(검증됨) |
| 컴파일과 콘솔 | L1 | 1 | 재컴파일, Unity 콘솔 조회 | 오류 0개, 대상 파일 신규 경고 없음 | 완료(검증됨) |

첨부 정지 이미지는 색, 밀도, 선의 형태만 확인하는 참고다. 움직임은 영상의 일반 타격과 치명타 구간으로 비교했다. Blender 연결과 설치 실행 파일을 찾지 못해 Unity의 기존 파티클과 마스크 수식을 개선했다. 빌드, 실제 마우스 입력 전투, M2/M3, 그래픽스 API별 첫 사용 지연, 성능/메모리 예산과 주관적인 레퍼런스 일치도는 미검증이다.

## 40m 기본 시점 후속 검증

1차 근접 영상 뒤 기본 게임 화면에서 잘 보이지 않는 피드백을 받아 2026-10-26에 기본값을 보정했다. 백열 폭을 0.20~0.34m, 잔불 폭을 0.16~0.30m로 늘리고 밀도 2, HDR 밝기 6/4, 백열 수명 0.14~0.30초, 잔불 0.28~0.70초, 플래시 0.08초/1.1m로 맞췄다. 알파가 온전히 유지되는 구간도 수명의 15%에서 35%로 늘렸다. 코드 기본값과 저장 프리팹에 같은 값을 적용했다.

| 주장 | 수준 | 증거 등급 | 실행 수단 | 실제 결과 | 상태 |
|---|---|---:|---|---|---|
| 기본 시점의 일반 타격 표시 | L2 | 2 | 40m/FOV30/905x408 Game View, 기존 ReportHit 경로, 일반 타격 1회 | 백열선 13개, 잔불 7개를 5프레임 뒤 캡처. 확대와 몬스터 숨김 없음 | 완료(검증됨) |
| 기본 시점의 시간 진행 | L2 | 2 | 같은 카메라, 30fps 고정 시간 진행, Unity 카메라 66프레임 녹화 | 근접 이동이나 카메라 확대 없이 일반 타격 2회와 소멸 확인 | 완료(검증됨) |
| 변경 기본값의 수명/풀 정리 | L2 | 2 | Burst/Simulate/비활성화 계측 | 일반 21개, 14회 중첩 252개, 0.8초 뒤 0개, 상한 65개, 비활성화 0개 | 완료(검증됨) |

기본 시점 검수는 표현 경로의 직접 호출이다. 실제 마우스 입력 전투와 릴리즈 전투 연결, 성능/빌드/M2 검증으로 확대하지 않는다. 촬영 중 사용한 허수아비, 무적, 플레이어 위치, 고정 시간 진행과 일시정지는 씬을 저장하지 않고 플레이를 종료해 복원했다.
