## 1. 기획 요약과 목표

신시 주민 출신 전사가 산귀 영역에 토벌 거점을 확보한다. 짧은 고정 웨이브에서 정기·부적·공용 보스 입장권을 얻고 신시에서 수련과 조합을 준비한다. 별도 보스전에 도전해 재료로 장비를 제작하며 여우의 흔적을 따라 월백의 결계에 접근한다.

게임 제목은 **신시**, 저장소는 shinshi다. 사용자가 제공한 세계관 설정집(단군, 월백, 산귀)의 설정은 [세계관·서사](design/world-and-narrative.md)로 정리했다.

| 항목 | 기준 |
|---|---|
| 장르·시점 | 실시간 쿼터뷰 협동 액션 RPG |
| 플랫폼·언어 | PC Windows·키보드/마우스, 한국어 체험판 |
| 대상 | 직접 조작·스킬 변형·반복 성장과 1–4인 공략을 즐기는 플레이어 |
| 일반전 | 숲 전장 1개, 6웨이브·180마리, 평균 5–6분·제한 7분 |
| 보스 | 최종 2종×이지/하드 4전투, 한 번 10–15분 목표 |
| 첫 외부 체험판 | 검사·마검사·궁수, 숲 1개, 월백 이지 1개, 1–4인, 성장·보스 파티 경매·약초·물약 제작 |
| 팀·기간 | 진욱: UI/성장/맵, 기웅: 보스/몬스터/프롤로그/컷신, 민성: 나머지. 3인·2주 목표 |
| 목표일 | 2026-10-15. 가용 시간·보유 자산·실제 진행을 확인한 배포 확약은 아니다 |

플레이 차이는 부적을 획득·정제하여 고정 4기술의 동작을 바꾸는 준비와, 짧은 일반전에서 모은 티켓을 별도 협동 보스 공략에 쓰는 흐름에서 만든다. 신화 시대의 공동체와 스승이 적의 수장이 된 사건이 반복 전투의 이유다. 기존 게임에 없던 시스템이라고 주장하지 않는다.

## 2. 세계관과 서사 기준

| 입력 설정 범위 | 유지할 설정 |
|---|---|
| 1–2 | 고조선 건국 신화 초창기. 단군이 신시를 다스리며 인간과 신령이 함께 산다. 풍백·우사·운사가 자연의 흐름을 맡는다. |
| 3–4 | 산귀는 단일 종족이 아닌 총칭이고 대체로 인간형이다. 비적대·영역 방어·은둔 개체도 있으며, 단군은 인간의 삶을 위협하는 산귀만 토벌한다. |
| 5–8 | 여성으로 서술되는 이름 없는 여우는 신시의 학문·도술 스승이었다. 이름·가족·유한한 삶과 계승을 동경했고 인간화 약속에는 정해진 시기가 없었다. |
| 9–14 | 정체불명의 목소리가 인정과 이간으로 불신을 키웠다. 여우는 정제법 핵심을 빼돌리고 떠나 스스로 월백이라는 이름을 정했다. |
| 15–18 | 월백은 산귀에게 글·전술·부적을 가르치고 정제법을 산귀용으로 바꿨다. 부적은 불안정한 정기를 안정시키고 능력을 강화한다. |
| 19–21 | 주민 출신 전사가 토벌대를 이룬다. 회수 정기는 신시에서 정제하여 육체·장비를 강화한다. 산귀 부적을 확률 회수한다. 원문의 장비 소켓은 사용자 결정으로 효과 등록·스킬 부적창으로 변경했다. |
| 22–23 | 숲·인간 마을 폐허·오래된 제단을 거쳐 여우의 흔적으로 월백 결계를 찾아 연다. |
| 24 | 월백은 부적·도술·정기·여우의 신통력으로 싸우고 첫 실제 처치에서 죽는다. |
| 25–27 | 산귀 세력·정제 기술은 남고 흑막의 정체와 선택 이유는 밝혀지지 않는다. 인간과 산귀를 각각 하나의 선악 집단으로 환원하지 않는다. |

신시는 여러 인간 세대 동안 지속되었지만 인간의 나라는 아직 완성되기 전이다. 작품 내부 시간이며 실제 역사 연표로 주장하지 않는다. 플레이어는 현재 세대의 주민 전사로, 여우가 남긴 가르침을 인간 스승에게 이어 배웠다. 모두 월백의 직접 제자라고 정하지 않는다.

단군이 인간화 약속을 미룬 실제 속내는 끝까지 공개하지 않는다. “처음부터 뜻이 없었다”는 목소리의 말은 적대적 주장으로 제시한다. 월백은 자립과 인정에 필요한 땅·힘을 확보한다며 무력 확장과 인간 영역 공격을 정당화한다. 이간의 영향을 받았어도 침공을 선택한 책임은 그녀에게 남는다.

산귀 부적은 위험한 정기를 제거하고 술식을 인간에게 맞게 재해석한 뒤 등록한다. 실패는 원료 손상·해석 불완전으로 설명하고 재료를 소모한다. 비적대 산귀는 대화·조사 조력자이며 적 목록·채집용 처치에 포함하지 않는다. 계약 신령은 의사를 가진 상대와 합의해 힘을 빌린다.

월백 첫 처치만 이야기의 실제 사건이다. 반복 공략은 게임플레이이며 부활·분신·시간 되돌림 설정을 추가하지 않는다. 단군의 미공개 의도·흑막 정체는 의도된 서사 규칙이다.

월백은 인간화하지 못한 여우 영물이다. 인간이 되기를 바라지 않는다고 선언해도 인정받고 싶은 마음은 남아 있다. 신시의 전체 정제법은 단군이 관리하며 월백은 그 핵심 일부를 가져가 산귀에게 맞게 바꿨다. 정제하지 않은 불안정한 정기는 변질의 위험이 있고, 월백이 죽어도 보급한 기술은 남는다.

## 3. 핵심 플레이와 승패

| 기획의 축 | 규칙과 연결 |
|---|---|
| 짧은 토벌로 다음 성장을 준비 | 5–6분 일반전, 처치당 개인 정기·부적·티켓, 실패도 확보분 일부 보존 |
| 신시에서 기술과 자원을 준비 | 고정 4기술의 부적 변형·수련 배분·보스 제작/계승·생활 물약 |
| 읽고 피하는 협동 보스 | 무적 없는 회피·예고·방향 검격, 직업 강제 없는 1–4인, 티켓·제한 부활·경매 |
| 추적으로 드러나는 갈등 | 스승의 흔적·비적대 산귀·지역 해금, 침공 책임과 미공개 의도 |

신시 준비 → 숲 6웨이브 → 전리품 정산 → 신시 정제·수련·부적 등록/선택 → 티켓 확보 → 보스 공략 → 확정 보상·개인 재료·파티 경매 → 장비 제작/강화/계승 → 다음 조합·다음 지역으로 반복한다. 약초 채집과 물약 제작은 준비의 별도 흐름이다.

### 일반전

토벌대 생존과 적 섬멸이 목표이며 방어 대상은 없다. 6공세의 예정 적·잔여 적을 모두 처치하면 성공한다. 일반전은 5초 뒤 자가 부활을 무한 허용하고 체력 50%로 복귀한다. 전원 사망 중에도 제한 시간·적 상태가 이어진다. 전투 시작부터 420초 안에 완료하지 못하면 실패한다.

웨이브 처치 수는 **20/24/28/32/36/40**, 합계 180이며 1–4인 모두 같다. 적은 근접·원거리·돌진·정예 네 역할이고 최대 동시 활성 24마리, 출현 예고 1초다. 공세별 45–50초·공세 사이 5초×5·정산 20초로 5분 15초–5분 45초를 목표로 한다. 적의 세부 범위·피해·출현 시간은 전투 부록을 따른다.

### 보스

혼자 쓰러지면 실패한다. 협동은 사망 10초 뒤 스스로 복귀할 수 있고 파티 공용 3회를 사용한다. 성공한 복귀 체력은 30%다. **전원 사망 즉시 실패**하며 남은 부활과 대기 시간은 전멸을 막지 않는다. 동료 구조를 요구하지 않는다. 처치 성공 시만 보스 기본 보상을 지급한다.

난이도는 일반전·보스 모두 시작 인원으로 고정한다. 적 능력치 기준은 전투 부록의 고정 지역표이며 체험판 기준 Aref 644.32·Href 3541과 정식 첫 숲 기준 Aref 220·Href 1950을 구분한다. 일반 적 체력은 1/1.75/2.50/3.25배, 보스 체력은 1/1.80/2.60/3.40배, 공격 피해는 1/1.05/1.10/1.15배다. 도중 이탈·사망에 따라 낮추거나 캐릭터 성장에 맞춰 적이 강해지지 않는다. 모든 직업의 솔로·같은 직업 4인·혼합 파티 완료를 검증한다.

### 실패·포기

확보한 기본 보상·부적·새 티켓·기존 장비는 보존하고 **이번 추가 정기만 50% 손실**한다. 중도 포기도 같다. 실패 뒤 처치 기본 보상을 새로 지급하지 않는다. 보스 입장에 사용한 티켓은 돌려주지 않는다. 시작 전 연결 실패와 확인된 서비스 장애 취소는 서비스 부록의 별도 절차를 적용한다.

## 4. 조작과 전투 메커니즘

마우스 오른쪽으로 이동, 왼쪽으로 기본 공격, Q/W/E/R로 고정 기술, Space로 회피, 1/2로 소형/대형 물약, F로 상호작용·가능한 부활을 한다. 검사·마검사·궁수에는 Z/X/C 전용 행동을 배정하지 않는다. 키 변경·마우스 버튼 교환을 제공한다. 지점 기술은 범위 표시 뒤 확정하고 취소에는 자원·쿨다운이 들지 않는다.

이동 5m/초, 회피 3m/0.25초·쿨다운 5초·기력 0이다. 회피는 무적 없이 실제 공격 범위에서 벗어난다. 기본 공격은 무료, 공통 기력 기본 100·초당 10 회복이며 일반 기술은 기력과 쿨다운을 함께 쓴다. 입력 보관 0.15초·다음 행동 하나, 회피→물약→기술→기본 공격 우선이다. UI 조작은 전투 입력으로 전달하지 않는다.

발동 전 회피 취소와 발동 뒤 후딜 취소를 허용하되 확정한 기력·쿨다운을 돌려주지 않는다. 범위 예고는 실제 피해 범위를 포함하고 색·경계·기호·음향을 함께 쓴다. 방어 불가 공격을 별도 표시한다. 속박 등은 일반 적에 적용되고 보스는 명시한 일부 구간에서만 짧게 허용한다. 특정 직업이 필수가 되는 기믹은 두지 않는다.

## 5. RPG 상세 설계

### 캐릭터·기술

캐릭터마다 직업이 고정되며 다른 직업은 새 캐릭터로 성장한다. 별도 경험치·캐릭터 레벨은 없고 정기 수련·장비·부적 효과 레벨로 성장한다. 동일 직업 중복은 무제한이다.

| 직업 | 고정 일반 기술 4개 | 전투 역할 |
|---|---|---|
| 검사(사용자 확정) | 넓게 베기·돌진 베기·집중 베기·연환참 | CombatGirls 검 모션 기반 근접·접근·연속 검격 |
| 마검사(사용자 확정) | 마력검격·화염검진·봉인검격·뇌광검파 | Magical-Knight 검+마법 모션 기반 근접 검격·근거리 제어·중거리 검파 |
| 궁수(사용자 확정) | AR01 속사·AR02 후퇴사격·AR03 관통시위(대표)·AR04 산개사격 | 활 원거리 사격·사선 확보. 상세 수치·특성·클립은 [궁수 설계](design/archer-design.md)가 단일 기준 |

2026-10-07 사용자가 애니메이션 에셋을 기준으로 직업·기술·부적 설계 개편을 요청했고, 2026-10-08 세 번째 직업을 궁수로 확정했다. 검사·마검사·궁수 구성은 사용자 결정이며 기술명·수치·특성은 초기안이다. 후속 요청으로 서버 규칙과 저장 계약을 구현했으며 실제 모션·밸런스·다인 플레이와 구 진도 이관은 미검증/미적용이다. [구현 및 검증 범위](05-implementation-roadmap.md#2026-10-08-세-직업-구현과-검증)를 따른다. 외형은 기존 P09 커스터마이징을 유지하며 공급자 캐릭터 외형을 채택하는 결정이 아니다.

검사·마검사의 기본 공격은 근접 검격이며 마검사가 원거리 기본 공격을 자동으로 쏘지 않는다. 기본 3단 모션은 각각 유효 공격 요청 한 번에 한 타격씩, 동일 피해로 연결한다. 준비·연속 타격·장판·부적 수치는 [전투 기준안](design/combat-design.md)을 따른다. 궁수의 원거리 기본 공격·발사 규칙은 [궁수 설계](design/archer-design.md)를 따른다. 검사에 전방 완전 방어/반격을 배정하지 않는다. 무적 없는 회피·기력·4기술 구조는 유지한다.

Warrior=0/Sorcerer=1/Summoner=2와 기술 12개·T01~T12 효과 45개는 구설계 구현으로 보존한다. 신규 직업 Swordsman=3/Mageknight=4/Archer=5와 12기술·T13~T24 효과 45개를 별도로 추가했으며 저장 진도 변환은 하지 않았다. [애니메이션·이관 설계](design/character-animation-design.md)에서 후보 배정과 이관 게이트를, [구 직업 규칙](design/legacy-class-design.md)에서 기존 식별자의 의미를 확인한다. 신령 동료 2체·공명·강림 3개는 재사용 후보로 보존하고 궁수의 기능으로 사용하지 않는다.

### 부적 선택·등록·성장

신시에서 회수 부적을 소모하여 효과를 등록한다. 스킬별 보조 2단계·핵심 변형 1단계에서 하나씩 선택하고, 세 단계는 처음부터 열린다. 배운 효과만 선택하며 기술당 최대 3개·캐릭터당 최대 12개 활성이다. 장비 소켓 대신 스킬 부적창을 사용해 장비 교체와 독립적이다. **조합 변경은 신시에서만** 한다.

신규 등록은 같은 효과 부적 1개+정기 150을 매번 소모한다. 효과별 실패 보정으로 50%→65%→80%→100%, 최대 4번째 성공이다. 등록한 효과는 레벨 1에서 시작해 중복 부적·정기로 레벨 5까지 확정 강화한다. 선택의 3단계와 효과 성장의 5레벨을 구분한다.

원문 18절의 강한 산귀와 높은 물품 등급 부적의 연결은 최종 콘텐츠에서 유지한다. 이번 숲 체험판의 회수품은 일반 등급·효과 등록 레벨 1로 통일하고 높은 물품 등급 공급은 후속 지역 콘텐츠에 둔다. 물품 등급과 효과 성장 레벨을 혼동하지 않는다.

현재 설계는 검사·마검사·궁수 3직업·12기술·45효과(보조 30/핵심 15)다. 대표 기술 넓게 베기·화염검진·관통시위는 단계마다 2개, 나머지는 단계마다 1개로 직업당 15개다. 궁수 15효과의 수치·적용 규칙은 [궁수 설계](design/archer-design.md)가 단일 기준이다. 구 신령사 15개를 궁수 효과로 이름만 바꾸지 않으며 신규 설계 작성과 구현·이관·체험판 수용을 구분한다.

레벨 1–5 성장계수는 1/1.15/1.30/1.45/1.60이며 부적이 더하는 보너스만 강화한다. 기존 기본 기술 전체를 다시 배수로 키우지 않는다. 범위·행동 교체는 처음 등록부터 작동하고 수치만 성장한다.

### 능력치·수련

기본 능력치는 공격 100·체력 1500·방어 100·치명타 확률 5%·최대 기력 100이다. 치명타 피해는 200%다. 피해 계산·장비 수치·반올림·감소율은 성장 부록을 따른다.

공격·생명·방어·치명·기력에 총 100단계, 항목별 최대 40단계를 투자한다. 수련 전 기본+장비 능력치를 기준으로 공격은 단계당 +0.5%, 체력 +1%, 방어 +2%, 치명타 확률 +0.5%p, 최대 기력 +1이다. 장비 교체 뒤 같은 투자로 효과를 재계산하고 수련이 자기 결과를 다시 증폭하지 않는다.

총 투자 k번째 비용은 `100 + 10 × (k−1)`, 100단계 누적 59,500정기다. 신시에서 별도 정기를 내고 기존 투자량을 재배분하며 투자한 단계 자체를 복제하거나 새 정기를 지급하지 않는다. 재분배 비용은 총 투자 N 기준 `200+20N`정기이며 배분 변화가 없거나 N=0이면 0이다. 100단계 배분 변경은 2200정기다. 항목 40·총 100을 넘기는 투자나 재분배 요청은 정기를 소모하지 않고 거절한다. 계산식·표시 절차는 성장 부록을 따른다.

### 장비·인벤토리

무기·머리·몸통·손·발·장신구 6부위, 일반→희귀→영웅→전설 네 등급이다. **일반전에서 완성 장비는 떨어지지 않는다.** 첫 보스 이지/하드가 일반/희귀, 월백 이지/하드가 영웅/전설 제작 재료를 준다. 경매 희귀 재료는 장신구 제작에 사용하고 다른 다섯 부위의 필수 재료로 넣지 않는다.

제작은 보스 재료만 소모해 강화 0 새 장비를 만들고 이전 장비를 남긴다. 강화는 최대 25강·확률 성공, 실패 시 재료만 소모하고 장비와 현재 단계를 보존한다. 실패 보정은 **캐릭터·부위·현재 강화 단계별 공유**이며 일정 실패 뒤 확정 성공한다. 비용·성공률·최대 시도는 성장 부록의 단계표를 사용한다.

계승은 같은 부위로 정기를 내고 원본을 소모한다. 같은 등급은 원본 단계 유지, 상위는 원본 17강부터 한 등급 위만 허용한다. 이번 이미지의 재련 단계로 기존 25→12 규칙을 대체했다.

| 원본 강화 | 17 | 18 | 19 | 20 | 21 | 22 | 23 | 24 | 25 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 상위 등급 결과 | 10 | 11 | 12 | 13 | 14 | 15 | 16 | 18 | 20 |

19–25 대응은 [첨부 이미지](design/references/inheritance-stage-table.png) 직접 입력, 17/18→10/11은 위임 보완값이다. 아이템 레벨·고대 명칭은 사용하지 않는다. 등급 기본 장비 수치는 직전 등급의 1.35배, 강화 배율 `1+0.04×단계`로 모든 대응에서 해당 장비 능력치가 증가한다. 대상 강화 0·착용 해제, 확정 계승과 전후 능력치 표시를 적용한다.

정기·강화 전용 정련편은 캐릭터별이다. 보스 제작/생활 재료·미등록 부적·물약은 계정 공동 보관, 등록 효과·레벨·수련·장비 성장은 캐릭터별이다. 제작 장신구 치명 2%p(수련용 1%p)는 등급·강화와 무관한 고정값으로, 계승 증가 계산은 공격·생명·방어에 적용하고 고정 치명은 유지한다. 스택·보관 상한·가득 찬 상태의 획득 보호·분해·착용 귀속은 성장 부록의 인벤토리 규칙을 따른다.

### 임무·대화·저장

임무는 미개방→진행 가능→진행 중→완료 조건 충족→완료 순서다. 지역·첫 처치·흔적은 계정 진행이며 실패로 되돌리지 않는다. 필요한 출정에서 성공하면 조건을 기록하고 신시 보고에서 다음 목표를 표시한다. 반복 전투 보상과 일회 이야기 상태를 분리하여 보고·재접속으로 중복 보상을 주지 않는다.

체험판 안내는 이동·기본 공격·기술·회피·물약→첫 6웨이브→정제/수련/부적 등록→티켓/월백→경매/제작 순서다. 분기 결말·호감도 수치를 체험판에 넣지 않는다. 주요 대사·본 장면 상태는 계정에서 다시 확인한다. 신시 서비스 NPC와 비적대 산귀는 대화 기호로 표시하고 공격 대상에서 제외한다.

성장·채집·제작·거래·티켓·획득·정산은 재화 차감과 결과 지급을 함께 확정한다. 보상·해금은 한 번만 지급하고 전투 복귀 상태는 30초마다 남기는 목표다. 저장 중/완료/재시도 상태를 보여 준다. 저장·복구 방법은 [기술 설계](03-technical-design.md)의 계약을 따르며 실제 장애 복구는 구현 후 검증한다.

## 6. 보상·경매·성장 속도

| 일반전 개인 획득 | 초기 기준 |
|---|---|
| 확보 기본 정기 | 완료한 웨이브마다 100, 6웨이브 성공 600 |
| 추가 정기 | 처치마다 8, 웨이브 완료마다 10, 완주 1500 |
| 성공 정기 합계 | 2100 |
| 강화용 정련편 | 완료한 웨이브마다 20, 완주 120·캐릭터 귀속·실패 시 확보분 보존 |
| 보스 입장권 | 몬스터마다 독립 0.5%, 완성 공용 티켓 |
| 부적 | 몬스터마다 개인 2%, 자기 직업의 15개 효과 중 획득 |
| 완성 장비 | 드롭 없음 |

접속 중 또는 120초 복귀 유예 안이고 이탈 정산 전인 원래 참가자에게 처치/완료 보상을 지급한다. 사망자도 포함하고 포기/유예 만료 정산 뒤의 이후 보상은 없다. 4인에서도 180마리 각각 자격자에게 개인 판정하며 막타 경쟁을 요구하지 않는다. 완주 시 티켓 기대 0.9장·한 장 이상 확률 약 59.43%, 부적 기대 3.6개다. 같은 파티에서도 티켓·부적 획득 결과는 달라질 수 있다. 이미 확보한 티켓은 실패에도 보존한다.

보스 입장권은 계정 공유·모든 보스 공용이며 전원이 1장씩 쓴다. 영구 해금은 티켓을 대신하지 않는다. 시간·일간 입장 횟수 제한은 추가하지 않는다.

보스 처치 성공은 모든 보상 자격자에게 기본 정기·거래 재화를 확정 지급하고, 일반 제작 재료는 개인 확률 판정한다. 희귀 장신구 재료는 개인 보상이 아닌 파티 경매 전용이며 한 번의 출현 판정을 공유한다. 등급별 재료 이름·수량·확률은 성장 부록이 기준이다. 새 거래 재화는 **보스 성공 기본 보상에서만** 생기고 거래/분배는 기존 잔액을 이동한다.

보스 기본 정기·엽전과 개인 재료 지급을 확정한 뒤 경매를 시작한다. 파티 경매는 최저가 100·최소 상승 10·품목당 30초, 남은 시간이 10초 미만일 때 접수한 유효 입찰은 남은 시간을 10초로 연장하되 품목 시작부터 최대 120초다. 낙찰자를 제외한 해당 품목 자격자 중 종료 때 접속한 사람에게 균등 분배한다. 수수료 0%, 정수 나눗셈 잔액은 소모한다. 입찰금은 예약하고 접수한 입찰은 철회하지 않는다.

솔로이거나 품목을 열 때 접속 자격자가 한 명인 경매는 동일 출현 확률·최저가 구매이며 대금은 소모한다. 여러 명으로 연 품목은 도중에 접속자가 한 명으로 줄어도 이 방식으로 바꾸지 않는다. 단독 구매 결정도 품목 기본 30초 안에 하며 연장은 없다(위임 초기안). 아무도 입찰하지 않거나 품목을 열 때 접속 자격자가 없으면 유찰·소멸한다. 미접속자는 새 입찰과 분배금을 받지 않지만 기본 처치 보상의 자격은 별도다. 재접속·최고 입찰자 종료 예외는 서비스 부록을 따른다.

초기 정기 500에서 수련 비용만 계산하면 성공 일반전 약 29회×5.5분=159.5분이 100투자의 산술 기준이다. 부적·장비·재분배 비용, 실패·채집·이동·보스 시간은 제외한 값이며 실제 완성 시간을 예측한 결과가 아니다. 부적 선택 변화·수련 선택·보스 제작이 서로 다른 시간대로 나타나는지 실측한다.

## 7. 생활·물약·유저 경매장·1:1 거래

채집은 토벌과 분리한 신시 인근 생활 구역의 공용 약초 한 종목이다. 생활 방 정원 8·노드 12개, 먼저 시작한 사람이 선점하고 3초 뒤 약초 2개를 얻는다. 완료 뒤 60초 재생, 취소는 선점을 풀고 행동력을 쓰지 않는다. 연결 종료 선점은 5초 뒤 해제한다.

행동력은 계정 공용·상한 100·완료당 2·5분마다 1회복이며 미접속 시간도 적용한다. 가득 찬 상태에서 50회·약초 100개, 0→100에는 500분이 든다. 캐릭터 변경·재접속으로 회복 시간이 초기화되지 않는다.

| 물약 | 제작 | 회복 | 전투 사용 |
|---|---|---|---|
| 소형 | 약초 5→1개 | 최대 체력 30% | 아래 공통 규칙 |
| 대형 | 약초 12→1개 | 최대 체력 50% | 아래 공통 규칙 |

두 종류는 공용 재사용 10초를 쓴다. 일반전은 지참 수량만큼, 보스전은 두 종류 합산 9회까지 사용한다.

물약은 계정 공동 재고에서 출정 때 지참량을 예약하고 사용한 완제품을 소모한다. 즉시 회복·0.35초 사용 표시·이동 가능·무적 없음이며 최대 체력을 넘는 회복은 버린다. 부활해도 잔량·사용 횟수·재사용 시간을 유지한다. 미사용 예약분은 귀환 때 반환한다. 재료 외 정기·거래 재화 비용은 없다.

유저 경매장은 생활 재료(약초)·미등록 부적 카드·거래 가능한 일반 등급 +0 장비를 같은 거래 재화로 정가 매매한다. **제작 물약은 초기 지원 물약과 재고가 합쳐져 구분할 수 없어 이번 출시에서는 거래 불가**이며 구분 설계 뒤 연다. 착용·강화·계승 장비와 희귀 이상 장비·티켓·보스 재료·정기·등록 효과·초기 지원품은 거래 불가다. 계정 등록 10건·24시간·성사 수수료 5%(구매 한 건 총액 기준 올림)·등록 수수료 0이다. 같은 마을의 가까운 플레이어끼리는 1:1 거래(품목 8칸 + 엽전, 수수료 없음)도 한다. **이번 체험판에 채집·제작과 함께 포함**하며 세부 값은 [체험판 경험 기본안 6장](design/experience-service.md)이 기준이다.

## 8. 지역·해금·이야기 경험

신시는 안전한 서비스 거점, 생활은 별도 공용 구역, 토벌과 보스는 출정 전장이다. 숲→인간 마을 폐허→오래된 제단→월백 결계 순으로 이야기를 열고 열린 지역은 자유롭게 반복한다. 신시에서 출정하고 정산 뒤 돌아온다. 전장 중도 귀환은 포기로 정산한다.

최종 초기 해금 순서는 신시 안내→숲 성공→폐허 성공→첫 보스 이지→첫 처치로 하드/제단→제단 성공 3회로 흔적 3개+첫 보스 하드 처치→월백 이지→월백 첫 처치로 하드다. 흔적은 결계를 한 번 영구 해금하고 이후 소모하지 않는다. 티켓은 매 보스 출정에 소모하며 파티 전원 해당 해금이 필요하다.

첫 보스 작업명은 **철각**, 월백 휘하 인간형 산귀 장수다. 고유 전투 제작은 후속이며 체험판에 추가하지 않는다. 월백은 두 번째 보스다. 체험판은 월백을 미리 연 전투 시험으로 정식 해금·첫 처치 이야기를 대신하지 않는다.

원문의 단군·풍백·우사·운사를 유지한다. 정제관 서린, 장인 담우, 의술사 여온, 길잡이 가람, 비적대 산길지기는 서비스/조사 역할의 작업명이다. 구체 기능과 전달 장면은 서비스 부록에 정했다. 체험판 프롤로그 90초, 정식 월백 첫 조우 45초·첫 처치 뒤 60초를 기준으로 잡고 주요 대사 기록·반복 장면 건너뛰기를 제공한다. 실제 컷신·모델이 확보되었다는 뜻은 아니다.

### 월백 1페이즈

[사용자 원안](design/combat-design.md#월백-1페이즈-실행-보완)의 P01 짧은 요력 돌진, P02 전방 부채꼴 폭발, P03 보스 중심 원형 여우불 폭발, P04 여우불 투사체, P05 지정 위치 여우불 장판, P06 대형 전방 요력 방출을 유지한다. ‘구미호’는 이 보스의 전투 작업명이며 꼬리 수 지정으로 확대하지 않는다.

전투 시작의 첫 선택과 매 패턴 종료 때 생존 플레이어 한 명을 무작위 선택해 거리·보스 기준 방향을 즉시 읽는다. 최종 가중치는 기본×거리×방향×주변 인원×최근 사용 배율이다. 합계 비율로 무작위 선택하며 가장 높은 패턴을 항상 고르지 않는다. 기본 가중치 20/15/10/20/15/8과 원안 배율을 그대로 쓴다.

주변은 5m 내 플레이어·전투 봇만 세고 소환물은 제외한다. 전투 봇은 원안의 집계 대상 표기이며 체험판에 봇 기능을 추가하지 않는다. 0명은 1명 열, 3명 이상은 3명 열을 쓴다. 일반 패턴 최근 순서 배율은 0/0.3/0.7/1, 돌진은 0.25/0.5/0.8/1이다. 밀집도는 초기 구현에 넣지 않는다. 경계·회전/조준 고정·예고·피해·방어/제어·모두 0인 예외는 전투 부록의 보완값이다.

월백 전체 체력은 고정 권장 공격력 700배, 50%에 2페이즈 전환 요청을 두는 시작값이다. **2페이즈 패턴은 다른 담당자의 설계 입력 대기**다. 1페이즈만으로 전체 10–15분 보스·다단계 체험판 완료를 검증했다고 하지 않는다.

## 9. 초기 지급과 계정 범위

정식 새 캐릭터는 일반 등급의 수련용 +0 6부위와 정기 500으로 시작한다. 수련용은 제작 일반 장비의 기본 능력치 50%인 지원품으로, 추가 등급을 만들지 않는다. 계정 최초에만 거래 불가 소형 물약 9개·행동력 100을 제공하며 새 캐릭터·삭제/재생성으로 물약을 반복 공급하지 않는다. 처음부터 부적 효과를 배운 상태로 지급하지 않는다.

체험판은 사용자가 정한 희귀 6부위 지급을 **+17**로 채워 월백 영웅 장비 제작→계승까지 바로 시험한다. 계정 최초 소형 9개·대형 9개도 시험 지원한다. 체험판 지원과 실제 보스 획득 규칙을 안내에서 구분한다.

| 계정 공유 | 캐릭터별 |
|---|---|
| 이야기·지역/결계/보스 해금, 거래 재화·공용 티켓, 제작/생활 재료·물약·미등록 부적·생활 행동력 | 직업·장비 성장, 정기·정련편·수련, 등록한 부적 효과·레벨·선택 조합 |

## 10. 협동·복귀·보상 자격

친구 초대·공개 방 목록으로 1–4인 파티를 만든다. 전원 해금과 보스 티켓·지참 물약을 확인하고 전원 준비 뒤 3초 카운트다운으로 시작한다. 장비·수련·부적·물약 변경은 준비를 해제한다. 시작 뒤 신규 합류는 금지하고 원래 참가자만 재접속한다.

연결 종료 캐릭터는 전장에 남아 피격 가능하고 사망 판정에 포함된다. 재접속 유예 120초, 기존 체력·사망·기력·공명·쿨다운·물약 상태로 복귀한다. 유예 만료 또는 명시 포기는 기존 실패 정산이다. 원래 참가자 전체가 포기/유예 종료하면 출정을 마감한다. 이탈 정산한 캐릭터의 전장 제거와, 보스에서 그 제거로 살아 있는 참가자가 남지 않는 경우의 처리는 [전투 부록](design/combat-design.md#난이도와-사망)을 따른다.

보스 처치 순간 접속 중이거나 유예 안의 원래 참가자는 사망 여부와 무관하게 기본/개인 보상을 받는다. 이미 이탈 정산된 사람은 이후 처치 보상을 받지 않는다. 경매 분배는 해당 품목 자격과 종료 때 접속 여부로 판단한다. 방 관리 권한 이동은 전투를 초기화하지 않으며 실제 연결 유지 방식은 기술 설계에서 확인한다.

## 11. 미술·음향·UX 방향

2026-10-01 사용자 교정을 반영해 **실사에 가까운 3D 스타일화 판타지**를 목표로 한다. 원화의 정돈된 큰 형태와 판타지 색감을 사용하면서 자연스러운 표면 디테일·마모·PBR 재료 반응과 조명을 유지한다. 부적·수묵 표현과 전투 가독성을 보존하고, 캐릭터 비례 등 별도 외형 기준은 [미술·음향·화면 기본안](design/experience-service.md#8-미술음향화면-기본안)을 따른다. 바닥·부유석·마을의 원화는 [컨셉아트 기록](design/concept-art.md)에 보존한다.

신시는 먹색·짙은 녹색 배경과 미색/청록 플레이어, 산귀 술식은 자주색이다. 전투 부록의 붉은 위험 경계와 이중 방어 불가 경계를 기준으로 삼고 황색은 상호작용/주의에 쓴다. 월백은 달빛 흰색 여우 영물 실루엣·꼬리 한 개를 작업 외형으로 잡는다.

아군 효과 밝기를 낮춰 적 예고를 가리지 않고 가리는 나무·구조물은 투명하게 표현한다. 공격 예고·피격·물약·부활·입찰 갱신의 짧은 효과음을 구분한다. 신시는 느린 타악/현악, 토벌은 중간 템포 타악, 월백은 낮은 현·날카로운 여우불 소리다. 기존 음원이나 유료 에셋 보유를 가정하지 않는다.

전투 HUD는 체력·기력·4기술·회피·물약 잔량을 보여 준다. 신규 검사·마검사·궁수에는 공명/강림 칸이나 별도 전용 자원 표시를 넣지 않는다. 구 신령사의 공명은 기존 구현 대조용이다. 일반전은 웨이브/6·시간·남은 적, 보스는 체력/단계·공용 부활·개인 복귀·물약 사용/9를 보여 준다. 성장·등록 화면은 전후 수치·비용·성공률·누적 보정을, 경매는 최고가·잔액·시간·분배를 보여 준다.

글자 100/125/150%, HUD 80–130%, 흔들림 끄기·효과 밝기 낮추기·색약 구분·자막·대사 속도·키 재지정을 제공한다. 위험/상태는 색만으로 전달하지 않는다. 세부 화면 목록·장면은 서비스 부록이 기준이다.

## 12. 기술 조건과 측정 목표

목표 엔진은 Unity 6000.4.7f1·URP, PC Windows 체험판이다. Mirror 96.11.3 기반 데디케이티드 서버를 사용한다. 방장은 출정 관리 역할이며 판정 서버를 뜻하지 않는다. 저장·전투 동기화·접속/배포 방법은 [기술 설계](03-technical-design.md)를 따른다. 이 문서는 복귀와 보상 경험·성능 목표를 규정한다.

1920×1080에서 평균 60fps 이상·프레임 시간 95백분위 25ms 이하를 목표로 한다. 검사·마검사·궁수 동일/혼합 4인과 활성 적 24마리, 검풍/검진/폭발/여우불 중첩을 포함해 10분 이상 측정한다. 궁수 4인의 최대 속사·산개사격 중첩을 포함하고, 구 신령사 4인·동료 8체·강림은 구구현 회귀 부하로 분리한다. 메모리 최대 4GB, 로컬 신시→전장 전환 15초 이하·입력 안내 표시 0.1초 이내를 초기 목표로 둔다. 실제 시험 PC·설정·서버 호스팅·배포 경로·접속 주소는 팀 환경이 필요하며 측정하지 않았다.

체험판을 외부에 전달할 실행본·설명·그래픽 가독성·안정성이 필요하다. 가용 자산 목록과 이용 권한, 배포 환경을 확인해야 목표 기간을 판정할 수 있다.

## 14. 성공 기준과 검증 상태

외부 체험자 8명·최소 20회 출정으로 검사·마검사·궁수 각각의 솔로, 동일 직업 4인, 혼합 4인과 서로 다른 네트워크 환경을 시험한다. 최종 3직업 체험판 수용에는 세 직업 모두의 구현·이관·실행 검증이 필요하다. 일반전 성공 시간 중앙값 5–6분, 보스 성공 10–15분, 성장 변화 이해 8명 중 6명 이상을 목표로 한다.

90분 연속 플레이·의도적 재접속 10회, 채집 동시 접근·티켓/물약·낙찰/분배·계승/실패 보정의 중복 지급/음수 재고 0건·완료 불가 오류 0건을 외부 배포 조건으로 둔다. 성장 속도·물약 공급·신규 직업별 피해와 기술/부적 후속 타격·예고 후 회피 가능 시간은 실제 관찰로 조정한다. 공명 주기는 구 신령사 회귀 시험으로 분리한다.

이번 문서 작업은 단계표·보상/비용 산술·부적 수량/ID·링크와 문서 간 규칙의 정적 확인이다. Unity 실행·게임 플레이·다인 접속·성능·실제 배포는 미실행이다. 설계 변경은 해당 본문과 관련 부록을 함께 갱신하고 변경 이유를 남긴다.

## 15. 범위·남은 입력·의존

최종 체험판 목표에는 생활 채집·물약 제작·세 직업·45개 효과·월백 이지·성장·파티 경매를 포함한다. 현재 3직업 12기술/45효과를 설계했으며 구현·저장 이관·실행 검증 전에는 체험판 완성으로 판정하지 않는다. 첫 보스·폐허/제단·월백 하드와 정식 이야기 해금은 후속 제작, 기존 최종 콘텐츠 목표는 유지한다. 유저 경매장과 1:1 거래는 체험판에 포함한다(구현됨·실행 미검증).

수련·성장 비용·드롭·채집·물약·경매·보상/복귀의 기존 초기값은 유지한다. 직업 개편의 기술/부적 수치는 새 위임 초기안이고 실제 모션과 조합 시험 뒤 조정한다. 아래 적용·검증과 외부 입력은 아직 남아 있다.

| 구분 | 남은 일 | 영향 |
|---|---|---|
| 궁수 적용 | 활/P09 모션·발사 회차·투사체·후퇴/관통/산개·15효과 조합의 구현·검증 | [궁수 상세](design/archer-design.md), 최종 3직업/12기술/45효과 체험판 수용 |
| 직업 개편 적용 | 검사·마검사·궁수 후보 재생·타이밍 재설계·부적 조합·코드/SO/저장 이관 | 긴 클립을 짧은 타격 예산에 강제 적용하지 않고 구 진도 보존 |
| 외부 설계 입력 | 다른 담당자가 만드는 월백 2페이즈 패턴·기믹·예고/제어 문서 | 월백 전체 전투와 10–15분/다단계 공략 검증에 필요 |
| 실제 제작 조건 | 3인 가용 시간, 모델·애니메이션·VFX·맵·UI·음향 자산/이용 권한 | 2주 외부 체험판 제작 가능성·일정 판정 |
| 기술·운영 환경 | 시험 PC/그래픽 설정, 저장·서버·접속·배포·참가 계정 운영 | 제작 기술 설계와 외부 실행 확인 |
| 플레이 검증 | 솔로/동일 직업/혼합 파티, 드롭·성장·물약 공급·경매 경제·성능/재접속 | 초기 기준값을 실제 적정값으로 조정 |
| 후속 콘텐츠 | 철각 고유 패턴·하드 변형, 폐허/제단, 정식 이야기 장면 제작 | 체험판 뒤 최종 2종·4전투·지역 구성 완성 |

단군의 의도·흑막 정체는 공개하지 않는 설정이므로 결정 대기 항목이 아니다. 17/18강 보완값·작업명·수치표·성능 목표는 사용자 위임의 초기 기준으로 채택했으며 다른 게임의 규칙이나 실측 결과로 제시하지 않는다.
